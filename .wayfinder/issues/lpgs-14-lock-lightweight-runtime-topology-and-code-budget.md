## Question

实现已锁定产品主干所需的最少运行单元、模块边界、数据库事实、异步机制、测试层和可观测性是什么？哪些现有系统合并、下沉、插件化、只读化或退役？后续如何用可执行边界阻止代码再次无价值膨胀？

答案必须给出按代码类别拆分的规模基线、目标范围、模块数量/依赖方向/公共 seam 约束，以及“每新增一层抽象必须换来什么用户价值”的审查规则；不得把删除测试和安全边界当作主要瘦身手段。
