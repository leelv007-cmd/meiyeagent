# ADR-0010: UIUX Upgrade Path B and Streaming Verdict

Status: accepted (2026-07-13)

依据 `docs/reviews/uiux-productization-gap-report-2026-07-13.md`（24 条经对抗验证差距、五根因）的复核结论，用户拍板三项决定：

1. **升级改造走路径 B（视觉 + 交互全面对齐 CreatOK/KickArt 范式）**。范围为该报告 §六路径 B 全项：路径 A 的交互层专项（token 流式、生成中反馈、参数形态、接线与假实现清理）加上开场引导层、降门槛层、候选择优层、骨架层、CheckBox 完整层、视觉/可达性层、一致性/合规展示层、统一输入台三喂料真实现。量级相当于第二轮 UIUX cutover：须重开验收矩阵增设"体验合同" required 条目，以对标产品逐屏截图验收替代纯功能验收，期间冻结新功能范围。报告 §六"共同前置"五项（拍板→工程票强制映射、验收矩阵体验条目、接线 owner 清点已建未挂能力、模板品牌残留一次性清扫、报错兜底与默认模式核心闭环可跑通）为 B 启动前置。
2. **流式口径冲突裁决：恢复 ADR-0007 的 token 级流式钦定**。副驾 chat 用 `streamText`、文案生成用 `generateObject`/`useObject` 部分对象流式、前端 copy-in prompt-kit `ResponseStream` + Streamdown-cjk 逐字渲染。UIUX wayfinding（2026-07-11）收敛出的"Job 级 progressbar、无 token 流式承诺"口径由本 ADR 修正废止；wayfinding 历史文档不改写，冲突处以本 ADR 与 ADR-0007 为准。长任务（图片/视频 Job）仍走异步 Job 观测，但生成中反馈须补自动轮询/推送与阶段白话叙事，禁假百分比口径维持。
3. **D4 候选策略不重开**：文案维持"一次 3 条 + 3 选 1 单选采用 + 换一批 + 免费重试 ≤2"（ADR-0008），不引入多选采用。当前缺失的是择优 UI 的实现（3 候选对比、换一批、免费重试入口），属实现缺口而非决策变更。

该决定来自 2026-07-13 差距复核后的用户确认，是对 ADR-0007/0008 与 `合集-v1.5-P0决策定稿.md` 既有拍板的重申与传导修复，不重开 P1 Scope Lock，不改变 ADR-0009 的单一发布 Gate。代价：范围约等于重做交互呈现层，风险中高，最大风险是重蹈"票关了体验没到"——因此验收以用户可见行为与对标截图为唯一标准，禁止以"后端就绪/组件完成"关票。
