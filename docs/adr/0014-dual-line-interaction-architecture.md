# ADR-0014: 双主线交互架构——对话流主容器与参数面板次入口

Status: accepted (2026-07-24)

> 本 ADR 凝结自决策日志 D-103/D-111/D-114/D-115/D-116/D-126/D-130（含 D-081/D-089/D-090/D-098 的 2026-07-24 修订标注），是实施投影；冲突以决策日志为准。

## Context

旧结构「单一生成工作台＋Agent 次模式＋提交后跳转结果页」已被 2026-07-24 批次取代。这是前端架构级反转，隔离阅读旧文档极易建错（2026-07-24 一致性复核的最大冲突群），故凝成本 ADR。

## Decision

**创作中心只有两条用户主线（D-103）**：

- **定制创作（默认主线）**＝agent 流式对话主容器＋AGUI 三层结构（D-114）：①对话流主线（意图→引导补问卡→计划卡流式→HITL 确认卡→额度卡→任务卡→成品预览卡）；②对象工作区纵深（成品卡点开进入，结果中心＝放大镜）；③任务卡时间桥（长任务可离场＋通知拉回）。session 是一等容器。`ContentIntent` 是①②段的**编译产物而非用户输入**——outputKind（copy/image/image_text_note/video）由意图编译推断，商家不显式选对口（D-081 的 radiogroup 必选合同仅在自由创作线存续）。**提交后不跳转**：成品在对话流内以成品预览卡流式呈现，点击成品卡才进入结果中心（D-089/D-090 的「提交即进入 Result Center」导航时点已按此修订；结果中心独立路由、ResultShellModel 唯一投影与命令合同保留）。确认卡一律「建议＋默认值＋超时自动继续」（D-116），引导永不变成新阻断。
- **自由创作（次入口）**＝参数面板式：用户显式选择媒介与模型原生能力，不隐式注入整套门店资料，不 agent 化，不另建 Harness。

**Day-0 与条件缺失（D-111）**：双入口分流——定制创作流内引导补充（意图驱动、可跳过），满足线＝本次意图能用上任何一类经营表达资产；不满足自然路由自由创作先出活并显式告知。录入永不前置（D-043 ≤2 击合同不变）。

**Dashboard 工作台首页（D-126，非 Landing）**：热态＝一天一个主推荐（为什么今天发/用了本店什么/希望顾客做什么），点击＝**预填充 Composer 非自动执行**，v1 依据＝确定性规则＋行业先验（admin-config 受控，不建推荐算法不接实时热点）；冷态＝三行业示例店（provenance=platform_sample 永不进真实 ContextBundle，真实资产录入即替换），示例任务＝真实执行扣试用额度，不建演示模式第二链路。

**流式合同**：token 级流式（ADR-0007/0010）由对话流承接——文案/图文自首个 token 起流式渲染，workflow 进度帧不得替代 token 流。

**组件供给基准（D-130）**：前端组件优先取自 **HeroUI Pro V3**（`@ag-ui/pro`，HeroUI v3＋Tailwind v4＋React 19＋React Aria；用户专属授权，本地镜像 `references/repos/herouipro-v3/` 不入 git、不对外分发）。适用面＝REBUILD 换壳与 NEW 净新建；对话流主容器优先评估其 AI Chat 组件族（chat-conversation/prompt-input/chain-of-thought/markdown/code-block）；D-107 后台动态表单＝HeroUI 表单组件族组装，不引 JSON-Schema 表单框架。KEEP 桶存量组件不为换库专项迁移（触碰时换）；「门店橱窗」（DESIGN.md）仍为唯一视觉权威，组件经主题 token 适配接入（主题拍板＝Glass——D-130 补充，Brutalism/Mouve 不启用），不得原样拖入。**Landing 页例外**：不受组件基准约束，保持现状仅改文案与前后链接（D-125 阶段一），专项优化后置（阶段二）；其余页面组件**与动效**均优先取自该库（动效随 Motion 体系，不另引动画库）。模板起点：`template/template-chat`＝工作区交互页（对话流主容器）参照；`template/template-dashboard`＝运营后台可视化参照；email/finances 两模板未指派、不擅自启用。

## 实施红线

- 禁止独立 Agent 首页、聊天泡克隆、floating copilot、与直接编排分裂的第二份草稿（存续告诫）；对话流是结构化卡片流，不是普通聊天记录，不得照搬「滚动灾难」。
- 禁止第二套提交真相：两条主线共享成品卡、对象工作区与同一 canonical command/账本链。
- 首页不自动生成成品；额度只在「生成」处消耗。
- 定制创作不出现槽位填表（D-031）；结构化输入以生成式 UI 融入对话流。
