# ADR-0015: ContentWorkspace 内容工作区与租户严格分离

Status: accepted (2026-07-24)

> 本 ADR 凝结自决策日志 D-121（含 D-102/D-119/D-123 关联合同），是实施投影；冲突以决策日志为准。

## Context

现有代码中 workspace/ws_* 全部是**租户语义**（安全与计费边界，单店单人 D-102）。D-121 引入的「内容工作区」是另一个对象：商家的个性资产容器。两者重名不同义，不立 ADR 几乎必然被复用错（绘文 styleId 复用人设 id 为反面教材）。

## Decision

**ContentWorkspace＝个性资产容器与引用上下文入口**：

- 账号 1:N 内容工作区；每个内容工作区与一个店铺或品牌 1:1 关联，承载独立一套个性资产（D-119 六类：门店/项目/团购/品牌元素/个人 IP/素材库）。
- **与租户严格分离**：它不是权限或安全边界。现有 workspace/ws_* 对象语义（租户）保持不变；ContentWorkspace 是**新对象、新表、新命名**（候选名 ContentWorkspace/BrandSpace），**禁止复用 workspaceId 或任何租户标识**。
- **引用作用域**：创作时 ContextBundle 从当前内容工作区解析；录入写入当前内容工作区；跨工作区资产不串。领域表挂内容工作区外键。
- **套餐一等维度（D-123）**：初级 1 个/中级 2 个/高级 3 个＋加油包单买；多品牌/多内容背景需求通过购买承接。数字为运营后台参数。
- **默认体验不变**：默认 1 个内容工作区＝D-102 单店单人体验原样；前台仅「工作区切换器」一处显现，无其他新增 UI 面。

## 实施红线

- 禁止复用租户 workspaceId/ws_* 对象、表或中间件承载 ContentWorkspace。
- 禁止把 ContentWorkspace 做成权限/成员/协作边界——D-102 单店单人不变，它不是多人协作入口。
- ContextBundle 编译必须显式携带当前 ContentWorkspace 作用域；任何跨工作区读取都是缺陷。
- 前台文案不得把两种「工作区」混用；商家语言只出现内容工作区（切换器），租户概念不暴露。
