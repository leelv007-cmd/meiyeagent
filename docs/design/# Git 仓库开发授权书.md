## 三、权限范围

1. 删除仓库、默认分支、标签或历史提交；
2. 强制推送或改写共享分支的提交历史；
3. 修改成员权限、安全策略或仓库可见性；
4. 将源代码复制、公开或提供给无关第三方；
5. 在仓库中提交密码、令牌、密钥及其他敏感信息；
6. 将仓库用于本项目之外的用途。

2. 提交信息应清晰说明变更内容；
3. 合并至主分支前应完成必要的测试和代码审核；
4. 未经授权，不得绕过分支保护、审核或持续集成检查；
5. 发现安全漏洞、数据泄露或异常操作时，应立即通知授权方。
