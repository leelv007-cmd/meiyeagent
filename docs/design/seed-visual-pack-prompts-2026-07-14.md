# 种子视觉包 · 文生图提示词合集（2026-07-14）

> 背景：逐屏对标发现产品"零成品图像"是廉价感的最大来源（详见 UIUX 差距报告根因与截图补充证据）。本合集覆盖产品全部需要种子图像的坑位，共 **40 条**。生成后交回，由接线票统一落盘（建议路径 `mkfast-template-main/public/seed/<分类>/<文件名>`，最终以接线票为准）。
>
> **通用规则（每条都适用）**
> - 画面内**禁止出现任何文字/水印/logo/UI 元素**——标题、价格、平台角标全部由产品 UI 层叠加
> - 人物均为亚洲女性/亚洲手部，肤色自然；手部特写注意手指数量正常
> - 统一光感：柔和自然光或高级影棚光，**暖白偏奶油色调**，避免高饱和艳丽（要小红书高级感，不要影楼感）
> - 负面提示词（通用）：`文字, 水印, logo, 英文字母, 数字, 低清, 过曝, 塑料感, 手指畸形, 多余手指, 脏乱背景`
> - 每条建议出 2-4 张挑 1 张；比例按各条标注
