## 二、跨屏共性差距（重构票直接输入）

把 9 屏 gaps 聚类为 **6 个主题**。每个主题标注涉及屏与最高严重度；这是屏级重构票与种子视觉包的直接输入。前 5 个为最高优先（均含 P0），第 6 个为派生的密度/层级问题。

### T1｜首屏零真实成品图 · 缺视觉锚点 —— 最高严重度 **P0**
涉及屏：**S1 / S4 / S5 / S6 / S7 / S8**（陈列/画廊型的 S4、领屏型的 S1/S8 最重；S7 表现为模型卡零视觉载体）。
- 核心表征：首屏折叠线上无任何真实成品图；示例素材是占位图标方块；陈列区是纯文字空态；模型卡仅文字 + 描边盒。对标以 hero 图 / 真实缩略图铺满约 70% 面积。
- 为何是代际差距：创作产品的第一价值锚点是“看到能产出什么”。当前用文字与配额数字占据黄金视觉位，第一眼即失质感。
- 直接影响：这是拉低 S1(3.0)/S4(2.5)/S8(4.0) 的首要原因。

### T2｜合规与工程术语占 C 位 · 防御性话术成墙 —— 最高严重度 **P0**
涉及屏：**S1 / S2 / S3 / S4 / S5 / S6 / S7 / S8 / S9（全 9 屏）**。
- 核心表征：素材合规三连问、免责声明、“持久化回执/唯一 Asset/事实与授权/资质 Preflight/BYOK/model.invoke/端点·路由/连接审计”等内部与工程术语，配上“密钥只写入不回显/不会复制示例事实/不表示因果归因”等防御长句，被摆到首屏正中或 H1 下首句。
- 为何是代际差距：这些是“我方自身合规义务与工程机制”，被前置为用户第一眼内容，把产品讲成了“控制台 / 台账 / 密钥网关”。对标把同类信息收进二级或用一句用户价值话替代。
- 直接影响：这是“整屏读作后台/控制台”定性的共同根因，横扫全部 9 屏。

### T3｜描边盒堆叠 · 重卡片感，缺背景明度分层 —— 最高严重度 **P0**
涉及屏：**S1 / S2 / S3 / S4 / S5 / S6 / S7 / S8 / S9（全 9 屏）**。
- 核心表征：单屏描边容器计数 S1 25+、S8 10+ 且卡中卡、S2 约 15、S9 约 10、S6 >8、S3 约 8；S5 更是填充 + 描边双重边界。对标靠背景明度分层，tab 无边、空态无框、主内容区去框漂浮。
- 为何是代际差距：逐个盒子描边制造密集的“表单/卡片”观感，与对标克制、有呼吸的浏览态形成体感代差。
- 可系统化：这是最适合用设计令牌（去描边 → 背景明度分层）批量解决的一项。

### T4｜无唯一主动作 · 多主 CTA 竞争 —— 最高严重度 **P0**
涉及屏：**S1 / S2 / S3 / S5 / S6 / S7 / S8 / S9**（S5/S9 为 P0，其余 P1）。
- 核心表征：主 CTA 旁并列“暂时跳过”；两个等重大按钮并排；生成初稿 + 浮动任务按钮 + 确认并保存三者争视线（浮动钮还压住输入框）；每张模型卡一个绿“本次使用”致 4 个同色主按钮 + 下方大绿“创建连接”；移动端任务铃 + 新建(+) + 拍摄素材三枚绿钮。
- 为何是代际差距：对标的“极简单动作美学”是第一眼有唯一落点；当前首眼无主次，多枚同色绿钮互相稀释。
- 可系统化：可用统一的 CTA 层级规范（主色只留一个，选中 = 状态而非按钮）收敛。

### T5｜空态反向劝退 · 脚手架占黄金位 —— 最高严重度 **P0**
涉及屏：**S1 / S2 / S3 / S4 / S6 / S9**。
- 核心表征：空态用“加载转圈 + 等待内置触发器创建新任务”反向劝退，无创建入口；“没有符合条件的对象 / 系统不会补入模板示例”冷硬防御；陈列区纯文字空态、无就地 CTA 只说教；“本周五点态势”五张卡全“暂无 0 条”占黄金视觉位、零 payoff。对标空态是“开始创作，你的作品将显示在这里”的温暖邀请。
- 为何是代际差距：新用户第一屏大概率是空态，当前空态在“劝退 + 说教 + 免责”，把首因体验做成了负资产。
- 可系统化：一个统一的“温暖邀请式空态组件”可批量覆盖 6 屏。

### T6｜密度过载 · 层级扁平缺呼吸（派生主题）—— 最高严重度 **P0（S1）/ 多为 P1–P2**
涉及屏：**S1 / S2 / S3 / S5 / S6 / S7 / S8 / S9**。
- 核心表征：首屏堆叠 8+ 分区密如表单无呼吸；13+ 字段标签同字号同字重铺满无分组；H1 与正文/标签同字号同灰度，中层字重色阶未拉开，缺三级跳；触区偏小、移动端将严重堆叠裁切。
- 说明：此主题多为 T1–T5 的连带结果（图像缺失 + 术语堆叠 + 描边盒多 → 必然密度过载、层级发浑）。解决 T1–T5 后需一轮“字重/色阶/留白/触区”分层收尾。

## 四、修复建议排序（按 投入/收益 Top5）

排序依据：单位投入撬动的跨屏收益。标注每项属于**“种子视觉包到位即解决”**（补齐真实成品图/缩略图/图标等资产即消除大半差距，无需重写布局）还是**“屏级重构票”**（须逐屏改版式/文案/交互结构）。

### 优先级 1｜落地种子视觉包（真实成品缩略图 + hero 领屏图 + 模型图标/厂商 logo）
- **性质：种子视觉包到位即解决**（配合极少量陈列容器改造）。
- 命中主题：T1（零真实成品图），并连带缓解 T6 密度感（图像面积天然建立节奏）。
- 命中屏：S1 / S4 / S8 首屏领屏，S4 / S3 陈列网格，S7 模型卡，S6 示例卡。
- 投入/收益：**投入中 · 收益极高**。这是“代际差距”评语的首要来源——当前把黄金视觉位让给了配额数字与文字空态。资产一到位，S1(3.0)/S4(2.5)/S8(4.0) 的第一眼质感即可跨台阶提升。
- 注意：S4/S3 的陈列区仍需一张小的“画廊网格容器”改造票配合（版式从仪表盘→画廊），但视觉主体由种子包供给。

### 优先级 2｜统一“温暖邀请式空态组件”+ 就地主 CTA
- **性质：以共享组件为主（低投入）+ 少量屏级接入**；示例卡视觉由种子包供给。
- 命中主题：T5（空态反向劝退）。
- 命中屏：S1 / S2 / S3 / S4 / S6 / S9（6 屏）。
- 投入/收益：**投入低 · 收益高**。新用户首因体验大概率落在空态，当前在“劝退 + 说教 + 免责”。一个统一组件（鼓励短句 + 就地创建入口 + 可选示例卡）即可把 6 屏的负资产翻正，是性价比最高的一票。

### 优先级 3｜合规/工程术语全局降级 + 用户语言化（文案 + 信息架构）
- **性质：屏级重构票**，但可用**共享文案规范 + 合规确认下沉模式**批量执行（非 9 张孤立票）。
- 命中主题：T2（术语/防御话术占 C 位）——唯一横扫全部 9 屏的主题。
- 命中屏：S1–S9（全部）。
- 投入/收益：**投入中 · 收益高**。做法：① 建“内部术语 → 用户语言”对照表（持久化回执/唯一 Asset/BYOK/资质 Preflight/因果归因… → 商家话）；② 合规确认统一后置为“保存/上传后的轻提醒”而非首屏表单；③ 删除无人索取的免责/防御长句（含 S7“密钥只写入安全存储”重复两次）。这是把产品从“控制台/台账”扳回“创作副驾”的关键一票。

### 优先级 4｜统一 CTA 层级规范（主色只留一个 · 选中=状态非按钮 · 浮动钮归位）
- **性质：屏级重构票**（须逐屏定主动作），但受统一交互规范约束。
- 命中主题：T4（无唯一主动作 / 多主 CTA 竞争）。
- 命中屏：S1 / S2 / S3 / S5 / S6 / S7 / S8 / S9（8 屏）。
- 投入/收益：**投入中 · 收益高**。规则可复用：每屏仅一枚绿色主 CTA，模型/tab 选中态改为“状态高亮”而非等重按钮，浮动任务钮移出表单区（S5/S6 当前遮挡输入框）。直接对齐对标“极简单动作美学”。

### 优先级 5｜去描边 → 背景明度分层（设计令牌）+ 密度/层级收尾
- **性质：设计令牌（系统级）+ 屏级重构票（逐屏应用与密度收尾）**。
- 命中主题：T3（描边盒堆叠）+ T6（密度过载/层级扁平）。
- 命中屏：S1–S9（全部；S1 25+、S8 10+ 卡中卡、S2 约 15 最重）。
- 投入/收益：**投入中高 · 收益中高**。令牌化“去描边 + 背景明度分层 + 分区留白 + 字重/色阶三级”，逐屏落地。属收尾性质：在优先级 1–4 落地后执行效果最佳（否则只是给密集表单换皮）。放末位是因其单位投入高、且部分收益依赖前四项先减少屏上元素数量。

### 落地路线小结
- **可先并行、见效最快**：优先级 1（种子视觉包）+ 优先级 2（空态组件）——一为资产、一为共享组件，均非逐屏重写，能在最短时间内把最低分的 S4/S1/S8 拉离“代际差距”区间。

- **收尾**：优先级 5（描边令牌 + 密度/层级）在前四项落地后统一收口。
