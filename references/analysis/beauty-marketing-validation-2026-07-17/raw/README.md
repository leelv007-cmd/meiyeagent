# 原始证据目录

本目录用于后续保存三平台研究中可安全持久化的 OpenCLI/只读浏览器原始快照；当前尚无不可变 raw 包。正式结论必须回链 `SOURCE-REGISTER.md` 和对应发现文件。

## 保存规则

- 只保存完成复核所需的公开字段、平台对象 ID、稳定 URL、抓取时间和命令；不保存 cookie、token、账号秘密或无关个人信息。
- 搜索结果与同店核身证据分开；搜索命中不能直接升级为门店样本。
- 小红书 URL 中的短期 `xsec_token` 在持久化前移除，保留笔记 ID、作者 ID 和稳定路径。
- 抖音日期只有在页面、适配器原始响应或其他可复核来源明确展示时保存；不把视频 ID 的推算时间当平台原始日期。
- 大众点评当前仅保存候选门店与详情摘要；无日期页面不得进入最近 30 天发布语料。

当前状态：三平台发现已完成，但本轮只在 `discovery/` 中保存了去敏字段、稳定 ID/URL、抓取时间和命令台账，没有把浏览器整页、会话参数或整段适配器输出复制成不可变 raw dump。该缺口已在 `TASK-CORPUS.md` 统计为未完成；后续补包前不得把当前目录称为完整原始语料。
