## 一、已确认事实（额度门外可见）

1. **入口交互 = 对话式单输入框**，不是表单：tiptap(ProseMirror) 富文本单框 + 2 个 tab（图文/文章类别）+ 快捷任务 chips（如「爆款标题」「选题灵感」）。零参数面板。
2. **「添加人设」是输入框内一等操作**——人设（persona）在提交前挂载，对应 API `/api/agent/persona`。
3. **双速toggle**（快速/深度类档位）在输入框附近，一击切换。
4. **单一「绘点」额度**：一种代币覆盖文本+图片消耗（vs 我们 D-109 双桶报价）。**绘点=0 时前端直接拦截提交，不发任何网络请求**（连 create 都不发，弹「绘点不足」）——额度门在前端最前置。
5. **量大管饱策略**：宣传「图文一次 50 套，可出 900 张高清图」——与我们 D-113「④段默认 1 主候选」相反方向；印证用户对火山抽卡判断：用数量对冲单次质量落差，代价是贵套餐。
6. **运营闭环侧栏**：选题中心 / 发布数据 / 账号空间 / 我的资产——生成工具外面包了一圈运营面。

## 五、对我们设计的即时启示（待用户拍板，不自动升级为决策）

1. **图文合一是「任务」级对象**：绘文没有把文案与图拆成两个提交，articleType=20 的任务一次生成全套——与 B-3 NotePlan「一次提交、plan-first、页级绑定」方向一致。
2. **平台专用编辑器路由**（xhsEditor）而非通用编辑器带平台参数——对应我们 D-112 `contentPackagePlatform` 一等字段的编辑面延伸。
3. **任务对象贯穿回流数据**：like/view/collect 直接长在任务上。我们的 ContentPackage→发布→数据回流目前是断的（发布数据无回流面），差距记录在案。
4. **额度前置拦截**（前端 0 点即拦）是商业面诚实体验的一部分；我们 D-109 双桶如落地，也需要前端第一击前的额度可见性。
5. **人设（persona）挂在输入框上**，不是设置页深处——上下文注入的用户感知入口做在了首击路径上。

## 六、生成管线实测（核心成果）

进入 `/agent?taskId=18210804` 后，左侧对话流以**时间轴节点**（✓ 可折叠卡片）展示全管线：

1. **确认文章细节卡片**（意图确认段）：创作类型=小红书、字数（空）；**主动列出建议补充维度**（夏季高发问题/高温皮脂腺活跃/头屑反复原因/夏季选品标准/温和成分重要性），说「补充后内容更具体、准确」——建议性不阻断；卡片内嵌**模型选择**（绘文 V4.1/V4、DeepSeek V3、Qwen 3、Kimi K2、Doubao Pro/Pro 2.1 共 7 档）、**创作总数（默认 2）**、**自动配图开关**；**「如未对卡片内容进行操作，20s 后任务将继续执行【继续】」——超时自动继续，非阻塞审批**。

## 八、编辑器与「加入到对话」回注

- 右侧编辑器（输入标题/输入文本）在生成完成后**保持空白**——成品不自动装载；每个版本卡片带**「加入到对话」**按钮（用户实测：点击后该版本调入编辑界面，供手动微调）。即：**对话流产出候选 → 显式装载动作 → 编辑器成为该版本的工作区**，对话流与编辑器是并列双容器，靠显式动作切换工作对象。

### 10.1 重大新事实

1. **模型 key 曝光**：绘文 V4.1=`gpt-5.2`、绘文 V4=`MaaS_o4_mini`、Qwen 3=`qwen-max`、Kimi K2=`k2`、Doubao Pro=`doubao-seed-2.0-pro`——自家品牌名下挂第三方模型，对客按**文风人格**分类（个性化/通用/严谨/灵动/口语化）+一句话 tip。模型呈现=文风定位而非供应商名，与我方「不暴露供应商」纪律同向，绘文把它做成了正向品牌资产。
