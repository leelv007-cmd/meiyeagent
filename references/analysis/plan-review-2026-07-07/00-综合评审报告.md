## 1. 总判

**产品方向成立，可以继续投入；v1.4 的五个方向级（P0）发现中，两项经用户拍板修正为更优方案：医美 = 资质准入制·轻量版（评审初判"撤回"过度泛化合规边界，见 D1）、部署与模型 = 阶段化（验证期 CF+混用最快验证，落地触发点启动备案与国内迁移，见 D2）；其余三项（合规义务主体重构、范围收缩、商业验证前置）维持评审结论待执行。**

一句话版本：

> 这是一门**红海缝隙里的重服务生意**，不是轻 SaaS。楔子（本地商家单轮 + 生活美业首发 + 创作副驾收敛 + L3 兜底 + 先验证后建设）判断正确；但竞争力不来自方案押注的"跨平台内容工作台"（已被平台免费工具和私域 SaaS 做掉），而来自"**合规服务化 + 门店数据飞轮（真实素材授权链）+ 陪跑运营关系**"三件事——而这三件事在当前方案里恰好分别处于：做错了主体（合规只做"提醒商家"）、做对了方向（素材/知识库）、没定价没测算（陪跑）。

交叉验证的可信度说明：五个角度独立作业，在"医美撤回""范围过载""合规义务主体错位""基建中国化"四个结论上互相咬合；关键外部事实（小红书 2026-02 医美禁令）由两个 agent 从不同信源独立检得。

## 2. 五个方向级结论（P0，须在拍板前处理）

### D1. 医美/医疗接入方式：资质准入制（评审初判"撤回"已被用户修正，2026-07-07 拍板）

**修订记录**：评审五角度初判建议撤回医美；用户否决并定方向——医美/医疗是正常经营行业、有正常宣传需求；平台已有商家准入门槛、AI 巡检与社区治理（小红书审核通过的专业号商家可发对应类目内容）；本产品是工具，应做规范筛选而非一刀切舍弃客户，"线下业务接洽筛选 + 线上提醒"即可。**采纳，并确认评审初判对合规边界存在过度泛化**：

- 平台 2026-02 治理的主要打击对象是**达人种草代发、无资质营销、三品一械带链接**；已过认证的商家自有账号在类目规则内保有官方发布路径——"整类禁推、内容合规也发不出去"表述过重（评审信源为二手报道，准确边界以实测为准）。
- "广告经营者"处罚先例（福州/三明代运营案）都是**受托制作**场景；商家自己操作的纯自助工具与之可区分（Canva/剪映不因用户制作广告而成为广告经营者）。风险真实存在但应通过产品定位与协议管理，不必品类回避。

**仍然成立、不因准入放开的底线**：
- 行为红线硬停止不变：疗效/安全性保证、治愈率承诺、伪造资质、未授权顾客案例、移除 AIGC 标识、绕过平台审核、处方药/未批药械宣传。
- 我方自身义务（AIGC 标识、备案 Gate 0、违法内容审核、滥用拦截，见 D3）与医美无关，照旧 P0。
- before/after 不做预置营销模板，改为**门控使用**：顾客单独授权凭证 + 广告属性警示 + 商家确认留痕后可用（人脸 + 医疗健康双重敏感，个保法/执法指南的真红线）。

**准入制落地设计（P0）**：
1. **线下接洽筛选**（闸门放在销售环节，不放在产品内逐条校验）：收集执业许可证、平台认证状态（小红书专业号/抖音认证等）、有投放需求另收广审证明，录入 workspace 资质档案；未过筛不签约。
2. **线上 Preflight 照 v1.4·轻量版（2026-07-07 拍板）**：ADR-0003"允许创作+发布前核验提醒"总思路**保留**（不需 supersede，只需增补"准入前置"条款）；线上环节做**纯提醒**——资质档案缺件时强警示，不做逐条门控确认（系统照常记录"提醒已展示"的日志，零交互成本，满足已尽提示义务的最低证据需求）。
3. **陪跑边界**：医美商家的陪跑限于工具使用辅导，陪跑人员不代写/不改写医疗声明性内容——守住"工具"定位，避免滑向"受托制作"。
4. **用户协议**：明确商家 = 广告主/内容责任主体，我方 = 技术服务工具；标识义务与责任归属写入协议。

**试点相应修正**：试点样本反向纳入 1-2 家已过平台认证的医美机构作探针（把 12-plan"排除医美"与产品"含医美"的脱节朝**含医美**方向修复）；Week-0 平台能力矩阵新增实测项——用真实认证商家账号验证小红书/抖音医美类目当前的商家侧发布权限边界（account-level verified 本来就是方案自己的口径）。

### D2. 部署与模型：阶段化策略（验证期 CF+混用模型 → 落地期迁移国内；评审初判"立即中国化"已被用户修正，2026-07-07 拍板）

**修订记录**：评审初判"立即国内云+国产模型、备案 Gate 0 立项即启动"；用户否决并定方向——选 Cloudflare 正是因为其对 agent 开发的支持性强（快速开发、快速上线、快速验证产品可用性）；模型国内外混用保证效果最优；产品真正落地后平移国内、下架不可用海外模型做取舍即可；产品还没有雏形就过度兜底合规，不符合 AI 原生的快速开发范式。**采纳，并确认评审初判与自己"验证前置"的原则相矛盾——把落地期约束错误前置成了立项期门槛。** 以下事实层保留（约束真实存在，但生效时点在"面向公众收费上线"，不在验证期）：

- **事实一（落地期生效）：CF 承载大陆商家端的长期生产部署不可行**：workers.dev 域名污染 + 自定义域 ISP 级封锁；唯一合规通路（CF 中国网络）需企业版 + 每域 ICP + 京东云内容审查（医美垂类是重门槛），与 4-10 周 P0 直接冲突；模板 R2 走 Worker 同源回源，大陆图片延迟/带宽双放大。而目标客户 100% 在大陆用手机访问。旧工作区 `13-p0-architecture-decision.md`（493 行）通篇没有任何大陆可达性/ICP/延迟评估——这个决策做出时根本没考虑中国部署。（04）
- **事实二（落地期生效）：AIGC 备案是公开上线的前置法定条件，且反向锁定上线时的模型选型**：面向境内公众提供生成式 AI 服务须**算法备案 + 大模型登记（省级网信办，周期约 1-3 个月）+ 页面公示备案号**，即使只调用第三方已备案模型 API 也不豁免；海外模型（OpenAI/Gemini/Claude）未备案且构成数据出境，公开服务阶段**一票否决**。旧工作区 `09-model-provider-eval-plan.md` 第一批文本供应商写的是"OpenAI、Gemini、DeepSeek"——作为验证期策略成立，作为落地期默认路由方向反了。（03 §一.2、§一.8；04）

**为什么会漏（方法论根因，防复发）**：底层决策的质量分裂很有规律——凡能用本地快照/原型**自证**的选型（渲染链、durable jobs、Postgres 事实源）质量都高；凡依赖**外部现实**（网络地理、监管、部署商）的选型全部出盲点。`13-p0-architecture-decision.md` L101 明写 "Live Sources Used: 无"——决策时根本没联网核实；CF 只在"运行时能力/体积上限"轴被评估过，从未在"大陆可达性"轴评估。而同团队在平台侧（05 号文档精确记录了小红书/抖音入驻门槛）明明捕捉到了中国国情，只是没把同一透镜用到基础设施和模型上。AIGC 备案则是更危险的"**已知但未传导**"：06 号文档 L485 用条件式"若…需评估"提过一句，但从未回流到模型选型（09 于是默认了境外模型）和部署决策（13）。（注：底层文档的问题是"从未评估过这条轴"——盲点；2026-07-07 用户拍板的阶段化是"评估后的有意分期"——决策。两者性质不同，防复发要求不变：ADR 必答外部现实轴。另：架构反转仍须写 superseding ADR——ADR-0002 是正式 accepted 状态，不能只改正文。）

**阶段化方案（用户拍板方向 + 评审补三条轻护栏）**：

验证期（现在 → 落地触发点）：CF + 国内外混用模型，最快路径——
1. CF Workers/Agents 生态 + mkfast-template 原生适配，开发摩擦最低；试点采用**封闭邀请制**（合同制、非公开注册），为国内 AI 产品 pre-备案 通行做法。
2. 三条轻护栏（服务于"平移便宜"和"验证信号干净"，不是合规仪式）：
   - **可移植性纪律**：领域逻辑写可移植 Node/Postgres（事实源本来就定 Postgres，Workers 经 Hyperdrive 连 Neon/Supabase 托管 PG），CF 专属服务（D1/R2/DO/Workers AI）一律走 adapter 接口——让"落地后平移"从口号变成低成本事实。
   - **试点数据卫生**：真实顾客人脸/手机号等 PII 不发往海外模型 API（涉顾客素材的任务路由国产模型或先脱敏）；生成内容保留 AIGC 标识；试点协议含数据同意条款。
   - **商家网络预检**：每家试点商家 Day-0 实测一次访问可达性并记录，把"打不开"从"不想用"的验证信号中剥离。
3. 模型：默认按效果混用路由；**国产模型同步进 eval benchmark**——不为立即替换，为落地日有质量对齐的平移对照，避免迁移日效果悬崖。

落地期（触发点启动，建议 = pilot Go 判定日）：
4. 触发点即启动长周期事项：算法备案+大模型登记（1-3 个月）、ICP（2-4 周）、国内云迁移排期——**绑定触发点而非"立项即启动"，也不是"到时再说"**：备案周期直接决定公开收费上线日期，Go 后立启动才不会让合规排队卡住商业化。Gate 0 语义改为"公开收费上线的前置门"。
5. 迁移动作：Node 服务与 Postgres 平移国内云、对象存储换 OSS/COS、默认模型路由切国产（benchmark 已备好对照）、海外模型转内部研发/评测用途、微信/支付宝支付接入。
6. mkfast-template 采用口径不变：**一次性取用 + adapter 隔离 CF 专属层**（源码实审约 30-40% 是 CF 专属：R2 深绑 `cloudflare:workers`、D1、wrangler；支付只有 Stripe/Creem、AI 模块只有 fal.ai/Workers AI）——adapter 纪律正是为了让平移日便宜。

### D3. 合规架构按"义务主体"重构：这既是最大的雷，也是最可能的真护城河

方案通篇把合规定位成"提醒商家核验，不替商家判断"。但有一整层义务的主体就是我方，提醒转移不了（03 §四列了 17 条，全部附法规依据）：

- **我方作为生成式 AI 服务提供者**（强制、产品必须内建）：AIGC 显式标识（含导出文件）+ 隐式元数据标识——方案里"如适用"三个字不成立，这是无条件强制；用户协议写明标识规范；违法不良信息审核 + 停止生成/报告机制 + 投诉举报入口 + 用户滥用拦截（连续 3 次/日累计 5 次规则）——当前合规 gate 只覆盖广告法/医美，这一层完全缺失。
- **我方作为受托处理者/潜在广告经营者**：DPA 六项必备条款、PIA、广告档案与 3 年留存、配备广告审核人员、证明文件不全不得制作。
- **商家作为广告主**：这一层才是"提醒 + 留痕 + 协议约定责任归属"。

**必须硬拦截的场景（行为红线，与医美准入制并行）**：处方药/未批药械宣传、疗效/安全性保证与治愈率承诺（已有）、伪造资质、未授权顾客案例、移除 AIGC 标识、绕过平台审核、违法不良信息与滥用（3/5 规则）。医美广告属性内容在资质准入制·轻量版下为**提醒制**：Preflight 展示资质/授权/平台规则提示（缺件强警示），不做逐条门控；before/after 沿用素材库已有的授权状态字段——素材上传时标记"顾客已授权"方可入内容（一次性标记，非发布时门控；人脸+医疗双重敏感的单独同意是个保法硬要求，不属于可降档的产品流程）。（用户拍板口径，见 D1）

**竞争力视角的反转**：市场报告判定"合规创作"是五件套里**唯一几乎无人正面做**的差异化（平台只拦截不给替代表述、通用 AI 不敢碰、垂类工具不做授权链路）——把上述强制义务做成产品能力（合规规则库 + 可操作替代表述 + 审计留痕 + 资质/授权管理），恰好就是别人不愿也不便复制的壁垒。**前提是按义务主体做对；照现在"只提醒"的做法，它不是护城河而是最大负债。**

### D4. P0 范围收缩：12 模块 → 7 项核心，4 服务 → 单体，砍掉 L2

- **过载判定**：P0 实际 = 12 模块 + 4 服务 + ~33 张表 + 服务端渲染管线 + 凭据保险库 + Agent 编排，对照"4-10 周 MVP"——这是 6 个月的量，不是 6 周的量；且与方案自己的"先验证后建设""不一开始绑复杂框架"自相矛盾。（05 §B1）
- **最小可赢集合（保 7）**：门店档案（精简）/ 真实素材库（上传+标签+授权状态，不做 pgvector）/ 文案生成（只小红书+抖音两平台）/ 内容库（草稿+已发布两态）/ **L3 发布包（做厚：扫码转手机/分段一键复制/图片存相册/发布 checklist，2026-07-07 拍板为 L2 的正式替代）** / 合规 gate（红线不砍，且按 D3 重构）/ 手工线索台账。**缓 6**：图文渲染管线（先 Canva/人工顶）、视频脚本可留（纯文本低成本）、能力矩阵四表、周报、完整账本、Durable spike。**砍 6**：L1 接入（只验证边界不写代码）、**L2 整体砍掉（2026-07-07 已拍板**；ToS 违约 + 群控案 260 万判例 + 托管 cookie 放大风险；砍掉托管发布后，凭据保险库这个最高风险子系统整个消失；pilot 埋发布耗时探针，P1 数据驱动再评估、扩展形态优先）、收件箱、Skills 版本系统、Sources registry、Permission 三模式（P0 只需"生成自动/发布人工"二态）。（05 §B2；03 §六）
- **架构（随决策 2 阶段化更新为 CF-first 适配版，即"架构 A"）**：P0 = **Workers 壳 + 单 Node 服务 + 托管 Postgres**——mkfast App Shell 留 Workers（官网/登录/BFF）；Core API + 渲染 + durable_jobs worker + 流水线合一为一个 Node 服务（CF Containers/Railway/Fly 均可）；Neon/Supabase 托管 Postgres 作唯一事实源（Better Auth 表也入 PG，双库身份分裂消失；Workers 经 Hyperdrive 访问）；R2 存二进制（走 adapter，落地日换 OSS）。四服务图保留为**演进终态**，标注三个拆分触发信号（渲染阻塞事件循环 / Agent 发版节奏分叉 / 数据库真实瓶颈）。（04）
- **Agent 框架（2026-07-07 拍板：B——AI SDK 起步，Mastra 推迟）**：副驾对话与流水线 LLM 步骤用 Vercel AI SDK（`streamText/generateObject` + zod 工具 + provider registry 承接国内外混用，可配 CF AI Gateway 做路由/缓存/成本观测；副驾对话可直接进 Workers 壳，架构 A 的 SSE 透传风险随之消失）；三条流水线 = durable_jobs + 自研薄 step-runner（约 300-500 行）；评测用 promptfoo 接 CI。**Runtime Port 铁律不变**（业务代码只依赖 `ContentWorkflowRunner` 接口）——Mastra 不是被否决而是被推迟，引入触发条件 = 流水线出现真实复杂度（多分支/子流程/人在环矩阵），届时只换 runner 实现。同行证据：CreatOK 生产架构零 agent 框架痕迹、自研 REST 状态机 + 轮询（`references/creatok/reports/creatok-architecture-estimate.md`）。这也兑现了方案 01 §7 自己的原则："不应一开始绑定某个复杂 Agent 框架"。
- **渲染链补漏**：satori（Yoga 布局，CJK 自动换行）应**第一天进主链路**（satori → resvg-js → sharp），不要按原计划"先手写 SVG compiler、后置 satori"——手写意味着要自己实现中文按字形断行，是加量不是减量；渲染跑 Node worker 不受 Edge 500KB 字体限制；字体用思源黑体（OFL）。渲染选型本身（10 号文档，5 候选原型打分）论证质量高，仅此一个子决策次优。（04）
- **CreatOK 吸收缺口回补**："生成即异步任务 + 任务历史 + 可恢复 + 失败 refund"要作为 P0 一等机制写进正文（Codex 数据模型契约已覆盖，合集正文丢了；这是 CreatOK 六条借鉴里唯一正文弱吸收的一条）。（05 §C）

### D5. 商业验证前置且加严：现在所有商业结论都是零商家接触的假设

**证据等级声明**：`12-merchant-validation-plan.md` L48 写明 "Live Sources Used：无"，15-playbook 的 Merchant Interview Findings 通篇是"应该写入…"的空模板——**目前没有一条真实商家数据**。方案里 ≤99/月止损线、60% 采用率、3/5 续费，连同本评审测算的价格带，全部是"待验证靶子"而非证据；即将执行的 pilot 是第一次真实读数。同时说公道话：15-playbook 本身比合集摘要严谨得多（准入 scorecard ≥70 才进 WOZ、operator/merchant 分钟数分记、Strong Signal Ranking 显式降权口头意向、单位经济 No-Go 条款、Asset Rights Gate 完备），**骨架健康不需推倒**——但按现状跑完只能回答"有没有需求"，回答不了"单位经济是否为正"，须补四项修补：

- **① 自助对照组**：WOZ 全程真人代做，验证的是"代运营+AI"而非自助 SaaS。给 operator 产出耗时设硬性天花板，Week 3-4 把 1-2 家切到纯原型（无人肉精修）读自助质量信号；Proceed 硬条件加"纯自助组 4 周留存 ≥50%"。（02 §9）
- **② 真实价格点**：试点赋价 Starter 199 / Growth 499，Go 门槛从"≥3/5 愿付费"改为"**≥3 家在 ≥399 档付定金**"——否则可能全体在 99 档达成"愿付"而 pilot 误判 Go（按单位经济 99 档是亏损档）。同时把 Go 判据里"续费、续跑或付定金"拆开——"续跑"是免费试用，不算付费信号。（02 §9）
- **③ 样本与时长升级**：访谈扩到 15-20 家，≥2 家付费续跑到第 8-12 周——4 周恰在 90 天流失窗口（SMB 约 43% 流失发生在前 90 天）刚打开时结束，看不到第 2 月悬崖。（02）
- **④ 招募即记 CAC**：按渠道记录触达→访谈→合格的耗时与花费，否则 pilot 跑完仍读不出 CAC——而 CAC<1500 是 Growth 499 档单位经济为正的三条件之一。（02 §9）

- **单位经济是最大空白**：测算显示 Growth 档可行价格带 **399-599 元/月**（留存 12 个月时 499 档毛利 +239/48%；留存跌到 6 个月即转亏 -91），正毛利三条件 = CAC<1500 / 首月陪跑 ≤3 人时 / 留存 ≥8 个月。99/月连 CAC 摊销都覆盖不了。定价锚点两头挤压：免费（抖音来客/绘蛙）— 69/月（讯飞绘文）——【我方 300-800】—— 2000-5000/月（代运营）。（02；01 §7）
- **陪跑必须产品化**：硬性人时上限（首月 ≤3 人时）+ 毕业机制 + onboarding 单独收费（300-800）——否则 WoZ 验证的是"人工代运营 + AI"，产品会不知不觉变成代运营。（02）
- **WoZ 指标修正**："70% 用户 5 分钟产出首条"在 WoZ（人工模拟）阶段物理上测不出来，挪到真产品阶段；WoZ 阶段改测：定金/预付家数、成品采用率、素材持续供给率、operator 分钟数走势。**0-4 周就上付费墙/fake-door 测真实付费，不要等 P0 做完再验价。**（05 §B3；02）
- **留存的真实断供顺序**：素材供给（第 3-4 周店主懒得拍）> 线索记录（手工台账反人性，大概率空表——而它承载着差异化叙事）> 内容质量（门票，海外同类头号流失原因是"内容套路化"）。对策：把"素材低摩擦采集"（手机随手拍即传/历史帖抓取/枯竭兜底拍摄清单）提为 P0 必做，并把"素材上传周频"列为北极星前置指标。（02）

### 3.2 差异化叙事从五件套收缩到三点

| 方案宣称 | 判定 | 依据 |
|---|---|---|
| 跨平台内容工作台 | **伪护城河**，6-12 个月被吞 | 微盟/讯飞绘文/番薯侠已做，无数据壁垒 |
| 内容生成质量/更懂你的店 | 伪护城河 | 通用 AI 商品化；Jasper（融资 1.43 亿美元）2025 死于被 ChatGPT 商品化 |

**接受一个身份设定**：这是"软件 + 服务 + 数据"的重服务生意。纯软件功能会被三面（平台免费、通用 AI、私域 SaaS）夹平。
