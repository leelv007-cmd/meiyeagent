#### 问题

- 标题“7月油头控油技巧：不塌”不够自然，语义像被 SEO 压缩过度。
- “马拉色菌”“代偿性出油”“水温 35–40℃”“二硫化硒/吡罗克酮/水杨酸”等是可核验主张，但最终结果没有提供逐句来源。
- “我更怕洗完紧绷”制造了第一人称体验，但没有真实作者身份或体验事实。
- 按“油/屑/敏”给个性化频次建议，若后续真的自动回复，需要避免把泛化内容包装成医疗个诊。

#### 发布建议

当前版本适合作为**需要人工复核的教育型草稿**，不应直接自动发布。至少需：

1. 为成分和护理建议提供可信来源。
2. 将“显微镜影像”改成“科普示意图”。
3. 删除或改写无真实主体支撑的第一人称体验。
4. 对严重、持续或伴随炎症的情况增加就医边界。

- 没有阻断未经用户提供的品牌植入。
- 没有检查 AI 产品图与真实包装的一致性。

## 5.3 复刻时的质量门

```text
传播表现评分 ≠ 事实可信度 ≠ 合规状态 ≠ 品牌一致性
```

四者必须单独呈现。候选 B 即使传播表现分高，也应被事实/合规门阻断。

## 6. 图片数量与资产合同审计

## 6.1 数量矛盾

| 层 | 承诺/结果 |
| --- | --- |
| UI 配图阶段 | 每篇 1 封面 + 4 内页 = 5 张 |
| 最终 `pictures` | 每篇 4 张 |
| 图片角色字段 | 无 |
| 失败说明 | 无 |

可能性包括：

- UI 文案写死。
- 封面包含在 4 张中，但文案错误。
- 其中 1 张生成失败，结果未显示部分成功。
- 图片列表被截断。

外部证据不能确定是哪一种，因此只能记录矛盾，不能替系统补解释。

## 6.2 资产持久化问题

最终合同只有外部 URL 和描述。若复刻：

- 必须归档到本项目对象存储。
- 生成 SHA-256 和 OwnedAsset。
- 记录生成模型、Prompt、尺寸、费用、审核状态。
- 保存封面/内页角色和段落位置。
- 对供应商 URL 过期提供本地可恢复副本。

## 7. 成品总体判定

| 维度 | 候选 A | 候选 B |
| --- | --- | --- |
| 主题匹配 | 良好 | 良好 |
| 小红书形式 | 良好 | 良好 |
| 可读性 | 良好 | 良好 |
| 来源可信度 | 不足 | 严重不足 |
| 事实可追溯 | 不足 | 严重不足 |
| 品牌中立 | 是 | 否，主动植入品牌 |
| 第一人称真实性 | 有轻微问题 | 严重虚构实测/体验 |
| 合规风险 | 中 | 高 |
| 可否直接发布 | 否，需复核 | 否，应阻断并重写 |

最终结论：讯飞绘文成功完成了“从一句话到两套图文候选”的生产编排，但其“内容生产完成”不能等价为“可信、合规、可直接发布”。对于美业健康护理场景，复刻时最需要升级的不是写作模型，而是来源治理、Claim-Evidence 映射、品牌事实边界和发布前硬门。
