# 移动端六卡与全屏创作目录（2026-07-20）

> 状态：`accepted_for_initial_release`（D-084）。用户选择方案 A：冷态完整展示六张快捷卡片，完整模板/工具使用全屏目录。首发组合可由后台后续发布新 revision 调整，交互安全合同不随运营配置变化。

## 1. 证据边界

- 小云雀桌面端已实际记录“主 Composer → 快捷提示 → 创作工具 → 精选内容”的层级，但本轮未实测小云雀、CreatOK 或讯飞绘文的移动端。
- 本决策不声称复刻竞品移动布局；它结合桌面竞品的信息分层、我方现有 320/390px 移动测试、当前代码结构与无障碍边界形成。
- 卡高、预览图比例和首屏露出量仍要在同一交互原型中实测，不在本条决策中伪造像素精准度。

## 2. 移动首页结构

快捷模板                                  查看全部模板
┌创作卡片───────┐ ┌创作卡片───────┐
└标题/副文案/动作┘ └标题/副文案/动作┘
┌创作卡片───────┐ ┌创作卡片───────┐
└标题/副文案/动作┘ └标题/副文案/动作┘
┌创作卡片───────┐ ┌创作卡片───────┐
└标题/副文案/动作┘ └标题/副文案/动作┘

冷态不选中任何对口，六张 D-082/D-083 卡片以两列三行完整展示。用户主动选中对口后，“快捷模板”切换为该对口最多四张 P0 卡片的两列两行。不使用自动推荐、默认对口或根据输入内容静默切换。

## 3. 视口与卡片合同

- 320px 与 390px 视口都使用两列；小屏不通过横向滚动隐藏核心模板。
- 200% 缩放或有效内容宽度低于 280px 时变为单列；标题、副文案和动作可换行，不用 line-clamp 截断重要信息。
- 每张卡片整体是一个 button，不嵌套按钮或其他交互控件；标题、副文案和明确动作共同构成可访问名称/描述。
- 动作文案始终可见，不依赖 hover；最小触区 48×48px，焦点不只依赖颜色或阴影。
- 缩略图是辅助信息。缺图、加载失败或关闭图像时，用户仍能理解并完成动作。

## 4. 点击、冲突与撤销

- 前五张卡片的明确动作是 `选择{对口}并套用`；这一点击就是 D-081 所要求的用户主动选择，不再增加一层无意义确认。
- 无受保护字段冲突时，在当前页本地套用 lens 与 Recipe patch，保留用户原文和来源，然后聚焦第一个缺失输入并提供撤销。
- 同对口手改冲突或跨对口切换才显示 `RecipePatchPreview`。移动端使用一张 bottom sheet，用实际差异说明“保留 / 暂存 / 改变”。
- “旧内容换平台”使用同类单层 sheet 选择来源、形式与目标载体；冷态对口和载体均无默认值。
- 浏览、套用、冲突预览、取消、撤销与返回均不创建 Work、Task、Job、ContentPackage 或额度预占。

## 5. 完整目录路由

“查看全部模板”和“查看全部创作工具”使用同一 canonical 全屏目录路由，通过 `kind=recipe | tool` 或等价 tab 进入对应内容。首版路由命名由工程计划与现有路由树合并决定，本文只锁定 canonical 语义：

- 目录使用全屏页面，承接长列表、分类/筛选、浏览器历史、深链、空状态和失败重试；不使用半高 sheet 载入整个目录。
- 未选对口时显示全部内容；已有 user-owned 对口时可把它明确显示为初始筛选，但筛选本身不会选择或切换 Composer 对口。
- URL 只允许 kind/tab、非敏感筛选、surface revision 和 return key 等引用。不把完整草稿、用户原文、素材授权、隐藏 prompt、Provider 或执行路由写入 URL。
- 返回恢复原页的草稿、已选对口、已套用 Recipe、滚动位置和触发点焦点；不要因返回重新套用或重新报价。

## 6. Overlay 规则

移动端全局只允许一个 overlay 状态，禁止嵌套 sheet。Bottom sheet 仅用于：

1. `RecipePatchPreview` 冲突确认；
2. “旧内容换平台”的来源/形式/载体选择；
3. 无法独立成页的一步窄工具确认。

系统返回、Escape、下滑关闭和取消走同一恢复合同：不变草稿，恢复页面滚动与触发点焦点。目录页、Pro Studio 和多步工具不塞进 sheet。

## 7. 后台配置边界

| 后期可发新 revision 调整 | 普通配置不得改变 |
| --- | --- |
| 卡片标题、副文案、预览素材 | 冷态六卡完整可发现 |
| 首页/对口精选项与顺序 | 320/390px 两列和极窄单列降级 |
| 模板/工具上下架与目录分类 | 模板、普通工具、Pro Studio 三种层级 |
| Recipe 默认设置与预计输出的同步更新 | 用户显式选对口、冲突预览与零业务写入 |

后台必须提供桌面/移动预览。发布校验要拒绝横向隐藏核心卡片、冷态只显示四卡、默认对口、动作文案与 Recipe lens 不一致或 Pro Studio 被混入普通工具卡片的 revision。
