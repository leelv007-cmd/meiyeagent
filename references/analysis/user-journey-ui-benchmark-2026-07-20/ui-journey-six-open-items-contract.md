# D-092～D-097 UI 与用户旅程六项联合合同

- 日期：2026-07-20
- 状态：`accepted`
- 用户选择：六项全部采用方案 B
- 范围：首批 standalone 工具、完整目录与搜索、条件 Brief、图片工作面、交付微合同、最近创作与通知

## 1. 最终组合

| 决策 | 已确认方案 |
|---|---|
| D-092 工具 | 多平台尺寸重排与导出、批量去背景、字幕擦除与修复、Pro Studio；显式 typed handoff |
| D-093 目录 | 模板/工具双 tab，任务语言分类，每 tab 12 个已发布可见条目后出现搜索 |
| D-094 Brief | 简单文案/单图直达；视频、复杂组合、高风险、权利或报价门槛触发紧凑 Brief |
| D-095 图片 | `single_image | ordered_image_set`，两张起套图，本机恢复七天，显式保存后跨设备 |
| D-096 交付 | `beauty-delivery-manifest/v1`、确定性 ZIP、文件→链接→下载降级、本人/外部责任人 |
| D-097 Recent | 桌面六条、移动四条，只通知关键可行动状态 |

## 2. 共同安全边界

- 浏览、搜索、筛选、打开工具、预览 Brief、查看证据、调整未采用套图和返回均不得创建业务任务、调用供应商或扣费。
- 所有跨页面上下文只传稳定对象 id/revision 与最小 typed state，不把 prompt、凭据、Provider 或敏感事实写入 URL。
- 任何模型执行、图片/视频生成或交付副作用都必须在用户明确提交后进入 canonical Task/Work/Job/Asset/ContentPackage/RouteSnapshot、报价、账本和审计链。
- 桌面、移动与跨设备入口解析到相同 Work/revision；显式目标不存在时不得回落最近对象。
- 后台可发布条目、排序、数量和文案 revision，但不能绕过能力发布门、Brief 安全触发、权利检查、QuotePolicy、动作预算或唯一真相。

## 3. 首轮验收

1. 四个 standalone 工具只有在能力/权益/数据条件成立时可提交；打开和返回 mutation 数为零。
2. 模板/工具目录在 11 项时不显示搜索、12 项时显示；URL/返回恢复 tab、分类、查询、滚动和焦点。
3. 简单文案与单图保持短路径；任何视频和其余命中条件的任务必须展示绑定精确 revisions 的 Brief。
4. 证据抽屉只显示真实参与草稿的来源事实，缺失、冲突、权利和新鲜度状态诚实可见。
5. 两张图片进入套图工作面；本机恢复七天，跨设备仅恢复用户明确保存且 base revision 未冲突的 selection。
6. 发布包 manifest 校验、文件校验和、ZIP 名称在相同 revision 下确定；系统分享取消不生成交付成功。
7. Assisted 24 小时未确认保持待确认并提醒，72 小时链接失效；已交接不投影为已发布。
8. Recent 桌面最多六条、移动最多四条；低价值进度不通知，通知点击进入精确 Result Center。

## 4. 非阻塞后续项

- 根据真实使用数据调整首发卡片、工具排序、Recent 数量或搜索门槛时，必须发布新 revision 并保留历史任务冻结值。
- 平台自动发布继续按逐平台 `automatic_verified` live gate 上线，不因 D-096 自动获得能力。
- Compatibility Work 保留期、错误绑定修复权限和供应商退款/usage 证据矩阵继续作为治理与供应实现细化，不属于本组六项 UI 架构开放项。
