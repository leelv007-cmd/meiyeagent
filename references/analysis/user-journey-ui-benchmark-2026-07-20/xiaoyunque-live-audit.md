- 产品：小云雀网页版（`https://xyq.jianying.com`）
- 采集时间：2026-07-20（Asia/Shanghai）
- 采集通道：OpenCLI Browser Bridge，独立 session `xyq-0720`，复用用户现有登录态
- 复用基线：`references/benchmark/interaction-study-2026-07-07/interaction-patterns-xyq-creatok.md` 与 `references/benchmark/interaction-study-2026-07-07/sources/xyq-2026-07-17-live.md`

## 1. 增量结论

2026-07-17 确认的“首页 Composer 轻任务 + 可选画布 project 复杂任务”双模型没有被新证据推翻。2026-07-20 更值得关注的增量是：图片和视频不再只是“通用 Agent 自动推断”，用户点击首页场景 chip 后，同一 Composer 会切换为明确的模态上下文，并立即改写可用素材、模型、参数、计价单位和下方工具推荐。

| 维度 | 图片路径 | 视频路径 |
| --- | --- | --- |
| 任务入口 | 首页“生成图片” chip | 首页“沉浸式短片” chip |
| 上下文反馈 | Composer 内出现“生成图片”标签 | Composer 内出现“沉浸式短片”标签 |
| 默认模型 | 明示 `Seedream 5.0 Pro` | 明示 `Seedance 2.0 Mini 体验版` |
| 核心参数 | 比例默认自动；二级菜单含 1K | 默认 10 秒；可调 4–15 秒；默认“全能参考” |
| 素材范围 | 图片 + 文档 | 图片 + 视频 + 音频 |
| 生成前价格 | 显示 `0/张`，划线原价 `6/张` | 显示 `4/秒` |
| 高级项 | 预设提示词 | 参考、Seed 设置、预设提示词 |
| 后续衔接 | @ 资产、画布模式、图片工具列 | @ 资产、画布模式、视频工具列 |

## 2. 图片生成旅程：当前确认

### 2.1 任务入口与意图输入

1. 首页保持单一中心 Composer，“生成图片”是直接可见的快捷 chip，不跳转独立页面。
2. 点击后 Composer 内增加“生成图片”上下文标签，placeholder 仍使用自然语言描述，支持 `@` 引用图片、视频、音频或文件作为参考。
3. 上传 input 在图片模式下收窄为图片和文档类型，反映任务上下文对可用素材的动态约束。
4. 输入框下方提供“咖啡产品宣传图”“小猫去旅游”“超火鱼眼镜头小猫”“爆款手办生成”等可刷新推荐词。本轮未点击注入，因此只确认入口存在，不重复验证注入行为。

### 2.2 结构化参数与 Auto 默认

- 图片模式不再显示通用壳的“模型自动”，而是直接预选 `Seedream 5.0 Pro`。
- 模型选择器当前可见 `Seedream 5.0 Pro` 、`Seedream 5.0 Lite`、`Seedream 4.0 美感版`、`旗舰生图模型 V2-Flash`、`Seedream 4.5`、`Seedream 4.1` 等选项，会员与限免标记也在同层呈现。
- 比例默认“自动”，可选 16:9（横屏）、21:9（电影）、9:16（竖屏）、4:3、3:4、1:1。
- 二级“更多”菜单将 1K 和“预设提示词”收起，避免首层参数继续增长。
- 生成按钮旁在提交前显示按张价格：当前 `0/张`，同时显示划线原价 `6/张`。这是当日活动状态，不应当作稳定商业规则。

### 2.3 生成前确认、结果与复用边界

- 空输入时未观察到额外的“确认生成”步骤；本轮不得由此推断有效输入后一定没有预检或二次确认。
- `@` 资产、画布模式、预设提示词与下方图片工具列为生成前复用入口。工具列在图片上下文中改为自由画布、三视图生成、图片多尺寸延展、品牌 VI、H5 长图、批量去背景等。
- 本轮未提交生成，无法新确认图片生成中状态、结果卡、局部改图、重新生成、下载或自动回流资产的当前实现。

## 3. 视频生成旅程：当前确认

### 3.1 任务入口与场景选择

1. 首页“沉浸式短片” chip 是轻视频生成的明确入口，仍在同一 Composer 内切换上下文，URL 不因此进入独立生成器。
2. 点击后出现“沉浸式短片”标签，同时将推荐词切换为“潮汕功夫茶宣传片”“猫狗偷玩手机一秒装睡”“特摄风猫狗大战”“漫剧：超绝人物特写”等视频意图。
3. 可上传范围随任务切换为图片、视频和音频，输入 placeholder 强调可用 `@` 指定素材作为参考。
4. 下方工具列切换为 SD 2.0 Mini、爆款复刻、运镜生成、一镜到底、首尾帧生视频、字幕擦除、知识类视频等与当前任务相关的后续技能。

### 3.2 结构化参数和生成前价格

- 场景入口直接预选 `Seedance 2.0 Mini 体验版`，而非继续使用通用壳的“模型自动”。
- 模型选择器当前可见 `Seedance 2.0 Mini 体验版`、`Seedance 2.0 Mini`、`Seedance 2.0 Fast VIP`、`Seedance 2.0 VIP`、`Seedance 1.5`、`Seedance 1.0 Fast` 等选项，会员门槛直接呈现。
- 默认时长为 10 秒；弹层中以 slider + 数值输入框调整，可用范围为 4–15 秒。
- 当前比例按钮只显示“比例”；本轮未展开该菜单，不把通用壳的“自动”直接外推为沉浸式短片的当前默认值。
- 参考模式默认为“全能参考”，可切换为“首尾帧”。
- “更多”菜单中收起“参考”、`Seed 设置` 和“预设提示词”，将专家参数保留在二级。
- 生成按钮旁显示 `4/秒`，但 10 秒默认时长下不在同屏直接显示预计总额。价格是当日账号与模型状态，不应外推为固定规则。

### 3.3 生成中、历史、结果与复用边界

- 本轮未提交生成，无法新确认进度态、估时、可否离开、站内通知、失败退还、取消、结果卡或整段修改动作的当前界面。
- “历史记录”页当前按生成类型分类，下拉可见“全能创作 Agent”“沉浸式短片”“智能成片”“一镜到底”“动作模仿”；默认“全能创作 Agent”筛选下为 0 条。
- 本轮按已确认范围停止扩展，未切换其他生成类型，因此不宣称整个账号没有历史任务。
- 2026-07-17 的护发门店宣传片 thread 样本和“约 18 分钟完成、结果提供重新生成/提升画质/字幕擦除”仍是可用的旧证据，但本轮没有重新打开该结果，不得将其表述为 2026-07-20 已复核。

## 4. 旧证据仍有效与当前无法确认

### 4.1 旧证据仍有效

- 首页仍是 Composer + 场景 chip/技能工具 + 精选作品的单一创作壳。
- 模型、比例、时长、参考与专家设置使用 pills 与二级弹层渐进展开。
- 首页仍有“画布模式”开关和“自由画布”入口；左侧创作历史当前仍显示两个“未命名项目 / 画布项目”，与 project 对象存在不矛盾。
- 由于本轮未进入 project，关于无限画布、四类基础节点、右侧 Agent、自动保存 UI 和项目资产 modal 的结论仍以 2026-07-17 证据为准，本轮没有增量复核。

### 4.2 当前无法确认

- 有效 prompt/素材齐备后是否有生成前的 brief 确认或二次确认。
- 图片和视频任务的当前异步状态、可恢复性、通知、取消、失败退还和晚到结果。
- 图片结果的局部改图、版本分支与复用方式。
- 视频结果的当前整段操作、是否可直接进入画布或时间线。
- 生成产物当前是否自动回流资产、对话文件或 project。
- 画布的刷新恢复、版本历史、共享权限、多人协作与跨设备恢复。

## 5. 对本项目用户旅程/UI 的直接启发

1. **值得参考：同一 Composer 内的任务上下文切换。** 场景选择后同时改写标签、placeholder、可上传素材、参数、价格单位、推荐词和工具列，用户不必进入多个割裂的生成器。
2. **值得参考：默认值 + 二级专家参数。** 比例 Auto、视频 10 秒、全能参考与二级 Seed/预设提示词构成明确的渐进展开。我们应使用“平台默认”“内容类型”“发布平台”等商户语言继续降低心智负担。
3. **不应照搬：将供应商模型直接放进普通用户主路径。** 图片与视频场景会直接预选并暴露多个 Seedream/Seedance 版本和会员标签。这对 AIGC 工具用户可接受，但不符合我们已确认的“用户选内部 CatalogModel，真实渠道与供应商隐藏”原则。
4. **我们要做得更清楚：显示预计总消耗。** 小云雀视频界面同时显示 10 秒和 `4/秒`，但用户需要自己换算总额。我们应在提交按钮旁直接显示“预计消耗 X 额度，余额 Y”，参数改变后即时重算。
5. **我们要做得更清楚：解释参考模式。** “全能参考”与“首尾帧”是紧凑的能力切换，但对非专业商户仍偏技术。我们应将其翻译为“参考整体风格/人物/动作”与“指定开场和结尾画面”，并用上传槽位说明需要什么。
6. **不应照搬：按技术生成类型分割历史。** “全能 Agent/沉浸短片/智能成片/一镜到底/动作模仿”的分类适合工具平台，但我们的商户应围绕“一条小红书笔记/一次活动/一个 ContentPackage”找回文案、图片、视频与发布变体。
7. **不应照搬：首屏强促销弹窗。** 本轮首次打开时出现遮挡主界面的 `Seedream 5.0 Pro` 全网首发弹窗，关闭后仍保留顶部公告。我们的模型更新应默认交由后台路由与非阻断提示，不要打断“今天该发什么”的主旅程。
