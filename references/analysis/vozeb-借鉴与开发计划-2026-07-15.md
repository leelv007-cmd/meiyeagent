## 0. TL;DR(一屏)

- **口径**:vozeb 全栈可复用为基座。不是"参照重写",是"拿现成代码改造 + 多租户化 + 堵洞"。
- **产品双层**:
  - **主力工作台层**(非技术美业商家 · 对话式外壳):素材生命周期闭环 + 图文素材创作能力。
  - **升单层**(中高阶/有自媒体经验商家 · 陪跑培训升单工具):无限画布 + 图片精修编辑,完整保留,独立于主力极简路径。
- **取消**:积分/签到/CDK;"素材永久可用"卖点包装(TOS 兜底工程仍做,不做卖点)。
- **移植三原则**:直接复用代码=连洞一起搬 → 每个模块必须 ①堵掉交叉验证审出的安全洞 ②做多租户化改造 ③配额结算挂任务终态。
- **序列**:先落 5 张横切底座票(B1-B5)→ 主力层 7 张(T1-T7)→ 升单层 3 张(U1-U3)。底座不先行,上层全是沙上建塔。

### 1.2 产品分层决策(用户拍板)

- **主力工作台层**:服务非技术商家,极简快生产,对话式外壳 + ContentPackage 结构化内核。
- **升单层**:面向中高阶(有自媒体运营经验)商家 + 陪跑培训场景的升单/增值工具,独立模块,主力客群看不到其复杂度。落既有 "L0-L4 换容器保内核 / Pro-代运营档" 框架。

### 1.3 取消项

积分 / 签到 / CDK(B 端订阅制不需要);"素材永久可用" 产品承诺包装(工程兜底仍做)。

## 2. 移植必修:交叉验证审出的问题(直接复用代码=连这些一起搬)

### 2.1 主报告 8 处失准 → 移植时的正确认知(否则会把弱实现当强实现搬)

| # | 主报告曾说 | 源码真相 | 移植影响 |
|---|---|---|---|
| M1 | SSRF 三处复用 DNS 全记录校验 | 仅副本下载一处;媒体代理是可绕弱黑名单;参考图不 fetch 远程 | 只有 `isSafeRemoteAssetUrl` 可信,余处须自建 safe-fetch |
| M2 | 真实 Base URL 只存服务端 | `x-vozeb-upstream-url` 响应头运行时全量暴露 | 移植渠道代理须删/重写该头 |
| M3 | 双校验杜绝注入 | 轮询链 queryPath 不重绑 + 带 Session Cookie = SSRF+Cookie 外带 | 任务侧协议配置必须服务端权威,不信任客户端 |
| M4 | 幂等结算 | 只是请求闭包局部布尔,无持久化 | 须换成持久化结算状态机 |
| M5 | 健康检查自动嗅探协议 | 首个 2xx 路径→预定义模板静态映射+手动保存 | 产品向导可做,别当端到端自动发现 |
| M6 | CDK 只存 hash | 明文+hash 并存进备份 | (CDK 已取消,免) |
| M7 | 公共库远程采集 | 离线固化种子,运行时零调用 | 采集器作离线数据管道,不进线上 |
| M8 | Agent 不塞 base64 | 选中图仍完整 data URL;拒绝即终止;归一化在线助手在前端 | 画布 agent 上下文成本与确认流按实况 |

## 3. 功能票草案

> 票格式:**目标 / vozeb 可复用模块 / 移植必堵洞 / 多租户化改造 / 验收 / 依赖 / 梯队**。
> 编号:B=横切底座,T=主力工作台层,U=升单层。

### 横切底座票(两层都依赖,必须先行)

---

**B1 · 模型渠道代理层**
- 目标:统一 AI 请求出口,隐藏上游 Key,承载多渠道(验证期海外 + 落地期火山/即梦)。
- 可复用:占位 baseUrl + 服务端注 Key + origin-gated 媒体鉴权(`includeAuth = origin 相等`);视频路径回退链 + payload 变体 + 错误分类两级重试 + 深度递归结果提取。
- 必堵洞:**A2**(method/path/model 白名单,未知路径默认拒绝);**M2**(删除/重写 `x-vozeb-upstream-url`,不向前端暴露上游地址);**M3**(任务侧协议配置只认服务端渠道,拒绝客户端提交的 queryPath/绝对 URL);**A6**(协议试探只在健康检测做,计费路径不试探)。
- 多租户化:渠道配置归租户/平台两级;BYOK 密钥按租户加密存储。
- 验收:①前端任何响应/日志均无上游 Base URL 与 Key;②未登记路径请求被拒且不触发上游;③兼容网关切换零改码。
- 依赖:无(第一张)。梯队:近期第一批。

---

**B2 · 异步任务中心**
- 目标:图/视频/文本生成任务的持久化、续跑、并发治理。
- 可复用:fire-and-forget + 任务表 + 心跳 30s/僵尸 3min/TTL 1h + 挂载扫描续跑 resumePendingLogs + 多候选轮询 URL + 图片并发 429 硬校验。
- 必堵洞:**A7**(先落 pending 记录再发创建请求,服务端幂等去重,创建在途刷新不丢);**A9**(并发计数与建任务原子化,防竞态超限);**A6**(重试仅限确认未产生上游任务/费用的错误类)。
- 多租户化:任务落 PG 非 globalThis 内存(多实例可用);并发上限按租户配额;上游显式 poll_url 支持但经代理重包装。
- 验收:①刷新页面进行中任务自动恢复轮询;②kill worker 后 3 分钟内任务转可重试失败态;③创建请求发出未返回期间刷新任务不丢;④单租户并发硬限生效且原子。
- 依赖:B1。梯队:近期第一批。

---

**B3 · 配额计费**
- 目标:条数配额的扣减/退回/对账,支撑 399-599 单位经济。
- 可复用:classifyPointsRequest 按路径+body 计价 + 模型单价表 + `__default__` 兜底 + 画质/时长倍率;先扣后退三通道(fetch 异常/非 2xx/abort)。
- 必堵洞:**M4**(持久化结算状态机:事务 ID+状态+崩溃恢复,替换局部布尔);**A2**(计费边界=授权边界,能触发上游消耗的路径必须显式计价或拒绝);**A6**(**配额结算挂任务终态**——成功终态才落扣,失败终态自动回滚,不以上游 2xx 为准);退款去重防 refund 重复加钱。
- 多租户化:配额账本按租户;计费规则服务端单一权威下发,前端不自持单价表(防漂移)。
- 验收:①异步视频任务失败自动退配额;②同一任务不重复扣;③崩溃重启不丢结算状态;④前端估算与实扣一致。
- 依赖:B1、B2。梯队:近期第一批。

---

**B4 · 媒体存储与安全出口**
- 目标:生成结果的存取、兜底、防盗链、安全抓取。
- 可复用:三层兜底(本地/远程/TOS 副本)+ `isSafeRemoteAssetUrl`(DNS 全记录公网校验)+ Range 透传 + 副本大小/超时限额 + 参考图临时公网化。
- 必堵洞:**A1**(所有服务端远程抓取——含图片任务参考图/结果——统一走 safe-fetch,references 加数量上限);**A4**(media-proxy 补 DNS 校验、MIME 白名单、nosniff、拒 IPv6 方括号/`localhost.`,置无 Cookie 独立 origin);**A3**(资源鉴权用不可伪造的 assetId+ownerUserId,不信任客户端提交的 serverUrl)。
- 多租户化:TOS 副本按租户前缀;副本删除仅 owner/admin;参考图 TTL 收紧(去掉 48h 叠加窗口)。
- 验收:①任意服务端抓取无法命中内网(含域名解析后指内网、重定向);②A 租户无法认领/删除 B 的副本;③视频拖动 seek 可用。
- 依赖:B1。梯队:近期第一批(与 T5 强相关)。

---

**B5 · 多租户与账号隔离底座**
- 目标:把 vozeb 的"单机/小团队"底座升级为真多租户 SaaS。
- 可复用:最后管理员保护;备份导入前快照留 3;离线密码重置(原子写/强制指定账号);生成日志查看器;资源对账清理。
- 必堵洞:**A8**(客户端所有本地存储 key 带 userId 前缀 + 登出清理并中断在途轮询);**A5**(初始化引导用 CLI/一次性 setup token,废弃"首用户即 admin");**A3/A2** 的授权模型统一(服务端 owner 记录为唯一授权依据)。
- 多租户化:PG 为唯一真源(客户端只做缓存);行级租户隔离;WebDAV/云同步按租户目录且不越权。
- 验收:①同浏览器切租户零数据串档;②登出后本地无残留创作数据、无在途轮询写入;③初始化不存在公网抢注 admin 窗口。
- 依赖:横切,B1-B4 的鉴权都收敛到它。梯队:近期第一批(与 B1-B4 并行设计)。

### 主力工作台层票

---

**T1 · 生成记录模型(工作台交互内核)**
- 目标:一个 ContentPackage 下多产物的生产交互。
- 可复用:GenerationLog(images/imageTasks/failures)+ resultsFromLog/buildLogFromResults 双向序列化 + 追加生成 slotIndex 尾增 + 失败原槽重试 + 多结果勾选保留/删除 + 记录重命名 + 丢失清理 + 序列化剥离大二进制。
- 必堵洞:失败重试挂任务终态(承 B3);记录真源落 PG 非 IndexedDB(承 B5)。
- 多租户化:记录归 ContentPackage 聚合(ADR-0011),客户端仅缓存。
- 验收:①"再来 3 版"是同包追加非新建;②单产物失败原位可重试;③勾选删除联动中断轮询+清副本。以图片工作台版为蓝本(视频版是 videos[]+单 task 混合体,须补齐到同等模型)。
- 依赖:B2、B3、B5。梯队:近期第一批。

---

**T2 · 一键沉淀闭环**
- 目标:打通工作台与资产页,形成"生成→筛选→沉淀→复用"复利。
- 可复用:素材系统 storageKey 引用式存储 + 从生成结果 addAsset + 导入导出 ZIP。
- 必堵洞:沉淀对象落 PG + TOS(承 B4/B5),非浏览器本地。
- 多租户化:素材归租户;引用式 GC 按租户对账。
- 验收:工作台任一产物可一键存为素材/模板,资产页即时可见可复用。
- 依赖:T1、B4、B5。梯队:近期第一批。

---

**T3 · 双 scope 模板/话术库(护城河落地)**
- 目标:官方策展库 + 商家自有沉淀库同一套基建。
- 可复用:`scope: library|user` + ownerUserId 隔离 + 同套 CRUD/检索/标签;种子版本化幂等注入(`:vN` marker 升级即替换不碰用户数据);mojibake 修复(采集异构中文源)。
- 必堵洞:采集器作离线数据管道(承 M7),不进线上运行。
- 多租户化:library=平台级,user=租户级;种子发布走版本化注入而非裸 migration。
- 验收:①商家私有话术/模板与官方库隔离;②官方模板升级不覆盖商家编辑;③标签检索复用同一基建。
- 依赖:B5。梯队:近期第一批(护城河)。

**T4 · 图片反推提示词 / 结构反推**

- 必堵洞:参考图抓取走 safe-fetch(承 B4/A1)。
- 合规:反推供自己再创作参考,不做直接抄图上架;红线提醒。
- 验收:上传图可产出结构化提示词/文案骨架,可编辑再生产。
- 依赖:B1、B4。梯队:中期。

## 4. 开发序列建议

1. **第一批(底座 + 主力内核并进)**:B1→B2→B3 串行依赖,B4/B5 并行设计;主力 T1/T2/T3 紧随(承底座)。这批完成 = 主力工作台可上多租户、素材生命周期闭环成立、护城河库落地。
2. **第二批(主力素材创作 + 支撑)**:T4/T5(素材创作差异化,带 A1 SSRF 必修)、T6/T7(运营支撑)。
3. **升单层(独立模块,排期对齐商业节点)**:U1→U2→U3。触发绑"开始陪跑培训 / 中高阶客群获客"信号,不与主力抢第一批弹药。

**红线**:B1-B5 未落地前不上任何直连生产路径;每张上层票的 DoD 必须显式勾掉其"必堵洞"列,否则视为把 vozeb 的洞搬进了我方 SaaS。
