## 1. vozeb 到底是什么(成熟度真相)

- **是什么**:个人优先、自托管站长可治理的多模态创作站;无限画布是专业编排层,不是团队业务系统。README 自己声明"不建议公网多人共用"。
- **证明到哪**:固定版本可构建、可启动、主要页面可进入;同浏览器内画布文字节点、个人 Prompt 两条轻量恢复。仅此。
- **完全未证明**:真实图片/视频供应商、Agent/MCP、双用户/跨设备、生产恢复、付费账务、真机触控、公网多租户。
- **结论**:功能密度高 ≠ 生产成熟。作参考语料与反面清单,不作产品壳/生产事实源。

## 2. 两条决策原则(对应用户要求)

1. **产品导向优先**:激活事件不是注册/签到/首次生成,而是**首个合格 ContentPackage 完成并进内容库**。任何后端强化,若不推动"更多合格成品/复用/交付/付费价值",按无效停止。
2. **反过度兜底**:后端接缝只有在出现"真实第二写入方 / 可控远程 URL / 付费跨设备承诺 / 持续性能瓶颈"时才建。没有对应触发,就不预建通用平台——先删抽象,不先拆服务。

## 3. 产品分层(一套事实,多个有边界的表面)

| 层 | 面向谁 | 能力 | 录取规则 |
|---|---|---|---|
| **L1 门店主力** | 非专业单店老板/店员 | Composer → ContentPackage | **必须完整面世,不是半产品**(当前焦点) |
| **L2 上下文深层** | 单店全体/熟练运营 | 轻精修、领域配方、素材复用、必要批量候选 | 从 owning Work/Asset/Package 进入并返回;真实摩擦触发 |
| **L3 Pro Studio(升单层)** | 工作区内已授权教练、陪跑成员、中高阶商户 | **无限画布 + 图片精修 + TTS/SFX + 受约束 Agent** | 能力/授权已锁定;**升单线现在并行启动(2026-07-16)**;不进门店默认导航,外部交付/公开销售过升单线验证门 |
| **L4 Ops** | 平台运营、客服、实施 | 模型供给、Job/成本、资源、配置、恢复 | 独立身份/壳,不进商家导航;薄起步 |
| **L5 生态** | 受审生态开发者 | 版本化 Command API、MCP、Provider Adapter | 第二写端 + 短期 capability + 幂等 + 审计成立后 |
| **Separate** | Private / Agency / 独立视觉 | 各自部署/协作/作品产品 | 独立买方、事实模型、GTM 与运维门,各自 Scope Reopen |

**不设全局"极简/专业"开关**。复杂度按当前任务渐进:轻编辑原地完成,复杂活动才进 Pro Studio,返回仍是同一 ContentPackage。

## 4. 现在做什么(唯一焦点:一套完整产品,一次面世)

不是可分别发布的小功能,是同一次发布门内的并行建设面。共同 DoD = 同一真实门店、同一组授权输入、同一 ContentPackage 贯穿业务/AI/媒体/确认/内容库/恢复。

| 项 | 内容 | 成功出口 |
|---|---|---|
| **K0 内核** | Product Core、ContentPackage、Postgres、Job/Provider/Asset/Template/Config/双账不变量 | 删任一外围 Adapter 后事实仍完整 |
| **N1 完整门店旅程** ★ | 真实商户→真实 LLM/媒体→Package→三平台 variant→确认→内容库 | 出现可计数的连续真实旅程(E5>0) |
| **N2 生产恢复门** | Postgres PITR、对象 inventory、配置 revision、KMS、隔离 restore | 声明 RPO/RTO,空环境恢复后一致;**付费即触发,无豁免** |
| **N3 Provider 语料/probe** | 脱敏 fixtures→sandbox→canary,不在计费路径试探 | submit/poll/download/cancel/费用/错误分类过门 |
| **N4 媒体 custody** | source→owned→Package 对账,missing 可修复 | lineage 可抽样对账 |
| **N5 桌面/移动同一 Package** | 移动只做采集/查看/轻编辑/确认/交接 | 换设备无第二事实源 |
| **N6 不可变发布候选** | 一个 digest 过 tenant/账/rights/SCA/迁移/恢复门 | 零跨租户写、零重复结算 |
| **N7 薄 Ops + 额度解释** | 授权人员不进数据库即可诊断/恢复;额度/成本用户可懂 | 账与投影一致 |

从 vozeb **借表达/思想**(非移植代码)的近端项:N3 借协议语料与 probe UX、N4 借 custody 标签与资源对账、N7 借 Ops 信息架构与额度解释、K0 的最后管理员保护+离线改密可照搬不变量。

## 8. 决策定稿(2026-07-16 用户拍板)

三项拍板 + 一处张力调和:

1. **框架 = 折中**(非全移植、非全触发):逐模块判断移植 vs 自建,判据见下表。
2. **第一批焦点 = 收敛到完整门店旅程**(N1)+ 上线恢复门(N2);后端能力按证据触发。
3. **升单层(画布/精修)= 现在并行投入**(不等业务信号触发)。

**张力调和(答案 2「收敛主线」× 答案 3「升单层现在投」)= 双线并行**:两线客群/DoD/发布面分离；共享 contracts/core/PG/wiring/主 Web 资源必须登记 owner 与合并顺序，不假装零碰撞。
- **主线 L1 门店旅程**:吃领域建模 + Provider + 恢复,Product Core 增量自建为主,vozeb 借思想。第一批资源收敛在此。
- **升单线 L3 画布/精修**:吃前端创作交互 + 复用获授权的 canvas/render/retouch core,面向工作区内已授权教练/陪跑成员和中高阶商户,独立变现,不依赖门店旅程完成,现在启动研发。
- **接缝(非折中)**:画布内核 + 精修**整套授权复用**,持有自身 `AdvancedCanvasProject + revision` 工程数据;与主线唯一对接点 = 某次画布产出被采用为成品时落回 ContentPackage。共享代码资源必须有显式 owner 与合并顺序；红线仅一条 = 画布不得冒充/覆盖已生成的 ContentPackage 成品事实。"并行投入" = 启动研发,进商家付费路径仍过升单线自己的验证门。

### 8.1 逐模块移植 vs 自建折中清单

判据:**前端创作资产(自建 XL、vozeb 成熟、授权可拿、安全洞影响小)→ 复用授权代码;后端事实/安全/账务(vozeb=单机反面教材,移植即背债)→ 自建。**

| 模块 | 折中裁决 | 理由 | 归线 |
|---|---|---|---|
| 无限画布内核 | **直接照搬复用(整套授权实现,不折中改造)** | 用户定:整套耦合系统拆改 XL 且易坏;升单线独立子系统 | 升单线主体 |
| 图片精修(蒙版/切图/放大/参考编辑) | **直接照搬复用(整套,不折中)** | 画布配套 | 升单线 |

> 画布迁移落地方案已定稿并入本文 **§9**(经 4 路 Codex 交叉验证)。

| Provider 协议兼容 | **借代码作脱敏 fixtures** | 兼容语料有价值;不进计费路径、不搬任意代理 | 主线 N3 |
| 最后管理员保护/离线改密 | **照搬不变量** | 行为通用、成本 S | 主线 K0 |
| 异步任务 | **自建(我方 Postgres Job)** | vozeb 单进程 Map 移植即背债;借心跳/续跑思想 | 主线 |
| 配额计费 | **自建双账** | Points 请求级结算不可作真钱账本 | 主线 |
| 媒体 custody | **自建** | 借 source/owned/replica 表达,不搬 URL 授权 | 主线 N4 |
| 安全出口 Egress | **自建·触发式** | 有远程 URL 才建;vozeb 弱黑名单可绕 | 主线(触发) |
| 渠道代理 | **自建 Provider Adapter** | vozeb 任意路径代理=SSRF;借 probe UX | 主线 N3 |
| 多租户/账号 | **自建(本就是 Core)** | vozeb 全局 store/首用户 admin=反面清单 | 主线 K0 |
| 提示词/素材库 | **自建领域配方** | 不搬 874 通用 Prompt | 主线 X2 |
| Ops 后台 | **自建薄 Ops** | 借信息架构,不抽 4k 行组件 | 主线 N7 |

一句话:**画布线移植授权码换速度,后端线自建换干净。**

据此修正:§3 表 L3 行、§5 触发器表画布行、§7 U1/U2 处置,均由"业务信号触发"改为"**升单线现在并行启动**";升单层从触发器表移出,作为与主线并列的第二产品线。

## 9. 升单线画布/精修整套复用 · 落地方案(定稿,2026-07-16)

> 草案经 4 路 Codex 独立交叉验证(报告在 `.scratch/vozeb-canvas-migration-2026-07-16/reports/r1-r4.md`,均附源码 file:line 出处),冲突已裁决,决策已拍板。

### 9.0 决策链(全部已拍板)

1. **产品框架**:日常应用工作台(Composer,非技术商家快出活)+ 高阶自由度定制工作台(vozeb 画布)**两档并存**;画布=高阶工作台,不抢日常档地盘。
2. **落地形态**:画布前端独立 + 生成接我方后端。
3. **复用口径**:画布渲染 + 图片精修**内核**整套照搬不改造;接入层(壳/鉴权/持久化/后端适配)允许改造(交叉验证证明接入层不改则方案不成立)。
4. **Polotno 处置**(修订原"取代"拍板——被 r1/r4 两路独立证伪:节点工程 vs 页式定稿不同层——用户重定):**冻结 → Composer 吸收日常轻编辑 → 过完删除门槛后退役**。vozeb 专心高阶档,不接页式版式定稿的活。
5. **首发范围**(用户定):**含 Audio 与画布 Agent**,不砍;升单线现在并行启动,不占主线(N1 门店旅程)弹药。

### 9.1 目标架构

```text
主力 SaaS(TanStack/Workers/PG)
  │ 一次性启动码(30-60s,绑 userId/workspaceId/projectId)
  ▼
canvas.<域名>  ← 独立 Next Node 服务,全屏顶层(非 iframe)
  vozeb 画布前端:渲染内核 + 节点模型 + 精修工具(蒙版/切图/放大/参考编辑)原样保留
  最小嵌入 layout(剥离 vozeb 顶栏/积分/退出/管理员入口)
  │ 统一同源门面 /api/canvas/*(不散改二十多个 fetch)
  ▼
我方后端(apps/core + PG):
  AdvancedCanvasProject(新,画布工程服务端持久化,替代 localForage)
  Generation Job(现有 durable)/ OwnedAsset / 双账 ledger / canonical history
  │ 专用采用命令 adopt_advanced_canvas_output(幂等)
  ▼
ContentPackage(唯一用户成品,不变)
```

首发接口边界:
- **CanvasBackendPort**(首发必需，画布↔我方后端):`load/save project、list/get asset、submit/poll generation、persist output、adopt to ContentPackage`
- **CanvasHostBridge**(仅 iframe/opener 嵌入形态启用，主应用↔画布):`ready / navigateBack / themeChanged / pickAsset / insertAsset / dirtyChanged / adoptOutput`
- 首发独立同页子域只依赖一次性启动码 + BackendPort，不得假设 HostBridge 已存在。

### 9.2 关键裁决与依据(四路验证收敛)

**领域模型(r1)**
- vozeb `CanvasProject`(节点图,连线=生成输入关系)与我方页式 `CanvasDocument` **不能无损互转** → 不做模型合并,不搞 `pages|graph` 联合类型。
- 新增独立对象 **`AdvancedCanvasProject` + 不可变工程 revision**(viewport/选区=可变 UI session;nodes/connections/资源引用=进 revision);不冒充 `WorkRevision`。
- "画布作品"契约留给页式 LayoutWork;"作品编辑上下文"原则扩展判别式来源 `layout_work | advanced_canvas | asset`;**Generation Job 契约必须保留**(vozeb 进程内 Map 不满足 SaaS 恢复合同),Job 来源从强制 workId 改判别式 origin。
- ContentPackage 唯一成品原则**不动**。采用接缝=专用命令 `adopt_advanced_canvas_output({projectId, revisionRef, selection, target: new_package|existing_package, idempotencyKey})`:冻结 revision → 服务端验证所选节点 assetId 已入自有存储、Job 达终态 → 经既有最高 Application Service seam 原子建包/建版本。`revisionRef` 只允许 `frozen` 或 `freeze_current_draft`；幂等身份=`projectId+resolvedRevisionId+normalizedSelection`，`orderedMediaNodeIds` 保留用户顺序（不排序）。同一项目/版本/选区无论 `new_package` 或 `existing_package` 再次提交，都返回首次采用结果或 `ADOPTION_ALREADY_EXISTS`，零副作用；target 不改变业务唯一性。不复用现有 `adoptIntoContentPackage`(强绑 CreativeWork 三候选语义)。source 只加结构化引用 `advancedCanvas{projectId,revisionId,selectedNodeIds,orderedMediaNodeIds,schemaVersion}`,不复制节点图。
- Audio 成品边界:ContentPackage 暂只有 `image_text|video` → 画布内 Audio 生成/复用完整支持(见 9.3),但**独立音频成品类型**需扩产品范围另行拍板;现阶段音频资产主要服务视频合成与画布内复用。

**前端形态(r2)**
- **首版=独立 Next Node 服务 + 全屏子域**;iframe 仅当必须保留我方外壳;SPA 抽取(脱 Next 嵌 Vite)是中长期收敛选项。
- CF Workers **跑不了** vozeb 原样(auth.json/参考图/日志依赖 node:fs 持久化)→ 独立 Node 进程/容器,与 apps/core 并列为独立发布单元。
- "6 处 Next 耦合"是表象:画布页无 props 接口、内嵌 vozeb 用户组件 → 做**最小嵌入 layout** 剥离,不动渲染内核。
- 样式:子域天然隔离,**不把 25 处 antd 重写成 shadcn**(违背保内核)。
- 鉴权:两边无 SSO(vozeb_session vs Better Auth)→ 一次性启动码换 HttpOnly 会话;禁止 URL 长期 token。

**后端适配(r3)**
- **"20 端点薄适配"口径作废**,按业务能力:7 已有、9 需扩展、4 真缺口(自由文本+反推、Audio、画布 Agent 工具合同、提示词库)。
- 三反面教材**整条拒绝迁移**:①任意路径代理→BFF 只暴露固定 action,客户端不得提交 channelId/baseUrl/path;②客户端 serverUrl 自授权→前端只碰不透明 jobId/assetId,日志降为 canonical history 只读投影;③Points 请求级结算→直接接我方 `FoundationModelSupplyLedger`(dispatch 前 reserve、交付 OwnedAsset 后 commit、失败 release)。
- **画布工程持久化必须服务端化**(localForage→PG),这是"整套照搬"里唯一不可豁免的内核邻接改造(跨设备/用户隔离/付费产品硬前提,r2/r3 双路同判)。
- 蒙版:mask 用有角色的 Asset ID,不把 data URL 塞通用 references;视频高级参数按 provider capability 显式声明,**计费路径禁协议试探**;ProviderReferenceGrant(参考图临时公网化)条件式——仅当真实供应商确认不收 data URL 才建,5-10 分钟 grant 绑 workspace+asset+job+attempt,过期即回收。

**Polotno 退役路径(r4,已拍板)**
- 爆炸半径:59 处引用(23 执行面);直接删断六条链(编辑器/文档适配/导出渲染/**水印+AIGC 标签烧录**/导出证据/素材来源+用户模板);CreationShelf 入口会创建打不开的 Work。
- 路径:**立即冻结(只维护打开/保存/导出)→ Composer 吸收日常轻编辑最小闭环(改文案/换图/裁剪/排序/预览/保存 revision/导出+合规标签)→ 过删除门槛后移除 SDK**。
- **删除门槛(全过才可移除)**:①轻编辑闭环由新实现接管;②历史 Work 可打开可导出(先做线上数据盘点);③水印/AIGC 标签/导出证据由新渲染器接管(**合规义务不可断档**);④CreationShelf 不再导向 Polotno;⑤测试/env/locale/依赖全迁移。领域测试不随 SDK 删——它们是新日常编辑器的验收。
- vozeb 对非技术商家过重(高置信)→ 只进高阶档,不进日常默认路径。

### 9.3 首发范围:含 Audio 与 Agent(用户定)及其真实代价

- **Audio(r3 评级 XL,新模态端到端)**:新 `audio.speech` + `audio.sfx` operations/catalog、provider adapter+任务恢复、Audio OwnedAsset/MIME、`Asset.mediaType` 扩展+播放器/下载/引用规则、用量计费、历史投影——全链进入首发。这使首发整体量级从 H 升为 **XL(超 5 周,跨新模态多领域)**,如实计入排期。
- **画布 Agent(r3 评级 H 增量)**:进首发的是**在线画布助手**,必须重建为服务器侧 allowlist 工具合同，固定七个动词 `read_canvas/create_node/update_node/delete_node/connect_nodes/disconnect_nodes/run_generation` + 逐命令用户确认 + apply_ops 三态结果(executed/changed/error)+ 快照版本绑定(防 TOCTOU)。工程现在启动，外部客户使用仍需真实净节时/费用验证与双会话零串写。**不进 SaaS build 的**:vozeb 本地 Agent 桥的不安全模式(URL 携带 agentToken、localStorage 存 token、自动连接静默关确认、通用 shell)——这是安全否决,与"含 Agent"不冲突。
- 提示词库首版用前端静态 seed(S 级),后续接 X2 领域配方。
- 仍不进首发:WebDAV、vozeb 提示词采集、签到/积分/CDK(已全局取消)。

### 9.4 实施顺序(升单线内部)

- **M1 骨架**:独立 Next Node 服务拉起(最小嵌入 layout)→ 启动码 SSO → `/api/canvas/*` 门面骨架 → 画布工程 PG 持久化(AdvancedCanvasProject + revision)。
- **M2 生成主链**:图片生成/编辑+蒙版接 Model Supply(mask Asset ID)→ 结果落 OwnedAsset → 双账 reserve/commit/release → 日志只读投影;自由文本/反推 `text.respond` 操作。
- **M3 视频 + Audio + 采用**:基础视频 create/get + 高级参数按 capability 声明;**Audio 全链**(operation/adapter/OwnedAsset/计费/播放);`adopt_advanced_canvas_output` + ContentPackage source 扩展 → 主应用采用回落闭环。
- **M4 Agent + 打磨门禁**:在线画布助手(allowlist 工具合同+确认+三态+版本绑定);条件式 reference grant;提示词 seed;安全验收(跨 workspace/伪造 serverUrl/幂等重放/异步失败退款/grant 过期/SSRF/**Agent 工具越权+双会话交错零串写**);首个验收闭环(登录进画布无二次登录/新建工程刷新+换设备恢复/插入我方 Asset/裁切+蒙版 AI 编辑/Audio 生成可播/助手建节点触发生成经确认/生成落 OwnedAsset/显式采用成 ContentPackage)。
- **并行(主线侧)**:Composer 轻编辑吸收 + Polotno 冻结,按删除门槛推进退役。

### 9.5 风险与守门

| 风险 | 守门 |
