# 合成：AI 原生用户旅程与分页排布重构（三源交叉）

- 日期：2026-07-08 ｜ 三路调研合成：KickArt 登录态实探+官方文档 / AgentKit 控制台实探 / ad_video_gen 源码三变体
- 触发：用户否定 W0-W8 线稿骨架——"卡片痕迹、传统交互痕迹明显，像上一个时代的产品，一点不 AI 原生"
- 分报告：kickart-findings.md / agentkit-console-findings.md / adgen-source-findings.md + sources/ 一手快照与源码留档

## 0. 判词：旧骨架的病根

W0-W8 的病不在单屏细节，在骨架是"**人找功能**"：4 个等权导航页、首页=卡墙货架（人逛墙）、创作=表单分步页（W2 槽位页→W3 传图页→W4 结果页）、发布/线索靠人记得去点。L0-L4 降低了每一步的门槛，但**步与步之间还是页面跳转、发起方还是用户**。Codex 1.0 版调研的传统 SaaS 基因（对象管理型 IA）只被局部修正、没被换骨。

三个参照的共同答案：**发起方换成 agent，页面换成流**。

## 1. 三源交叉的收敛点

| 收敛点 | KickArt | AgentKit | ad_video_gen 源码 |
|---|---|---|---|
| 主入口=意图态非配置态 | 中央意图框，三喂料同框（打字/贴链接/传素材） | "像我的场景"货架+一句话意图，编排折叠进默认值 | 一句话+可选图 URL 即启动 |
| 过程=分步旁白非页面 | Agent 自主分步：理解→创意→分镜→成片，过程即对话内容 | 执行链路可视化（对开发者是 Trace，对用户要翻译成人话） | CallBackAgent 每段播报"✅已完成X，继续Y"，partial 流式 |
| AI 给选项、人挑 | 一次 4 条创意+换一换 | 抽卡评估=天然人类介入点 | 候选 N→1 评估（美学/画质/一致性打分） |
| 产物即模板 | 做同款/灵感墙/局部重生成 | 货架式模板详情页（案例先行） | shot_list/brief 全结构化可复用 |
| 异步沉淀 | 任务中心/合成中心，不阻塞 | Runtime 会话沉淀 | session.state 黑板+JSON artifact 链 |
| 导航退位 | 轻侧栏 5 组，重心全压中央输入框 | 对外意图态、对内才是对象管理 | 无自定义前端，一个能渲染富媒体的聊天框 |

**反面教材（三源一致的缺口，我们的差异化）**：ad_video_gen 明文"展示后继续、不等待用户确认"（prompt.py:35-37）——零确认点对非技术老板娘=失控感。我们在 brief 确认、候选挑选两处保留**轻确认（改而非重填）**。

### 1.5 KickArt 官方文档补充（2026-07-08 追加）

- **同厂演进铁证**：同一文档中心挂着旧产品「智能创作云」（企业版/商家版/云编辑器/模板广场=典型传统多页 SaaS），KickArt 即其 Agent 化下一代——字节自己走完了"多页 SaaS → AI 原生对话工作台"的演进，是骨架切换的最强旁证。
- **定价数量级错配（警示）**：KickArt 为企业级订阅（基础版 ¥16800/月 600 创点、旗舰版 ¥32.8万/年、创点约 ¥25-28），面向电商商家/MCN/代运营。**页面范式可借鉴、商业模式不可照搬**；反面看，Agent 工作台骨架在 399-599 低价位段尚无人做=空位。
- **双合规门（可直接抄）**：输入端"确权按钮"（提交动作内嵌条款勾选，素材确权）+ 发布前"投前预审"，前后两道产品级合规门 + 《合规承诺函》协议——与我方"素材授权字段+采纳即担责留痕+Preflight"拼成完整链。
- **对象模型正解**：Project（由对话发起的顶层对象）→ 卖点卡片 → Storyline → Storyboard → 作品（沉淀"我的空间"）——**对话式外壳与对象化沉淀不矛盾：流里跑、库里存**，正是我们"创作流 + 内容库"的双层结构依据。

## 2. 新骨架：一个 Agent 工作台 + 轻侧栏资产页

```
主工作台（首页=产品本体）
├─ ① Agent 开场：拟人化问候+今日建议 chips（2-3 条，点一下即预填意图开跑）
│     "王姐，这周烫染还没新图——要不要先出一条老客召回？" [就发这条] [换个建议]
├─ ② 中央意图框："说说你想发什么"
│     三喂料同框：打字（可选）/ 拍照传图 / 粘贴文本（价目表/旧文案）
│     下方场景 chips 一行横滑：引流｜种草｜促销｜复购｜全部场景▾（货架收缩为伴随建议）
└─ ③ 创作流（对话式时间线，所有过程与产物都是流中卡片）
      brief 确认卡（结构化槽位预填：项目/类型/Hook/平台；价格不预填）→ 轻确认①
      → 进度旁白（"正在看你传的图…正在写开场钩子…"禁百分比）
      → 候选卡 3 选 1 + 换一批 → 轻确认②
      → 合规预审卡（四段式，医美采纳留痕）
      → 产物卡（采用可撤回/改稿 chips/做同款/去发布包）
      历史向上翻=创作历史；右下任务浮标=异步任务中心

轻侧栏（资产页×3，权重下降）：内容库 / 线索台账 / 门店档案（素材·价目·人设品牌音·资质·账号）
全局：额度 meter+按钮旁消耗 / 连接桥通知 / 移动端 bottom nav 5 槽（⊕=聚焦意图框）
```

**旅程对比**：
- 旧（7 次页面跳转，人找功能）：进门→逛卡墙→选卡→槽位页→传图页→等待→结果页→（记得的话）去发布→（记得的话）记线索
- 新（0 次跳转，agent 找人）：进门→agent 已备好建议→点一下/说一句→流内 brief 卡→旁白+3 选 1→合规→产物→agent 顺手问"要不要发/我帮你记一笔"

## 3. 与已拍板决策的关系（三类）

**原样保留**：任务四态白话旁白、退款分层（技术失败自动退/不满意送重试）、undo 优先、合规四段式、AI 标注可解释、品牌音、按产出量卖、L3 发布包全套（扫码转手机）、线索 data-table、bottom nav ⊕=新建内容、示例美甲店（改呈现为"agent 演示流"预置在时间线里，只读不计量）。

**换容器保内核（L0-L4 不作废，改嵌进流里）**：
- L0 卡墙（首屏主体）→ 场景 chips 一行+可展开货架（伴随意图框，不再占首屏）
- L1 少数语义槽位 + L0.5 逐槽确认 + L4 字段级预填 → 合并为流内 **brief 确认卡**（预填可改、逐槽 picker、Hook 脚本库仍独立成槽）
- "选中预设即隐藏提示词框" → 意图框不是提示词框（说人话+喂料即可），brief 编译不可见

**被 supersede（需用户点头）**：
1. "结构化入口第一、副驾对话第二"的**排序** → 改写为"**对话式外壳、结构化内核**"：外壳是意图态（agent 主动+一句话），结构化骨架退到 brief 确认卡里守事实（价格/平台/合规仍硬结构化，不因对话式而丢）。
2. **副驾浮球取消**——副驾即主台，不再另设浮层（该拍板产生于"卡墙首屏"骨架下，骨架换了它失去对象）。
3. W1 三段式首屏作废重画；W2/W3/W4 从"页"改为"流中卡"；W0 导航从 4 等权改为"1 主台+3 资产页"。W5-W8 结构保留。

**新增**：今日建议 chips（agent 主动提案）、候选 3 选 1+换一批（文案便宜可多候选；图/视频维持单发+免费重试）、发布前预审卡（KickArt 投前预审同构，与合规护城河咬合）、素材提交内嵌"确权勾选"（KickArt 确权按钮范式，接素材授权字段）。

## 4. 剥离项（电商基因不平移）

商品 URL 抓取（我方已实测降级为待研究专项）、100 条批量裂变、逐镜分镜编辑、跨语种复刻——电商投手/专业剪辑心智，美业单店用不上；专业能力默认收起（渐进展开铁律仍适用）。

## 5. 风险与待验证

- **打字恐惧**：意图框对老板娘的心理门槛靠"今日建议 chips+场景 chips"兜底（点选仍是第一路径，打字只是可选）；WoZ 期验证"建议点击率 vs 自主输入率"。
- **多候选成本**：文案 3 候选一次消耗一次额度（不按候选计），图/视频不多发；额度表述原则不变。
- **流式技术面**：与已锁组件路线咬合（AI SDK UI tool parts + prompt-kit + Streamdown/cjk），CallBackAgent"人话进度"范式由自研 step-runner 的 hook 实现（ADR-0007 不变）。
