## 0. 判词

两条路不是互斥选项，是**没有对齐到"层"**。把产品拆五层后，每层的买/建答案各自清晰：路 1 是体验层+垂类层+编排层的正确姿势；路 2 的"买成熟能力"精神在模型层早已成立（API 调用就是买），但"订阅 KickArt 套壳"落在错误的层（把别人的**产品**当自己的**底座**），三笔硬账不成立，降级为 P1 视频能力的 buy 候选之一、绑定触发点。

## 1. 五层 buy/build 边界（本轮核心产出）

| 层 | 买/建 | 具体姿势 | 依据 |
|---|---|---|---|
| ① 模型能力层（文生文/生图/生视频） | **买（API）** | 豆包/DeepSeek/即梦/Seedream/Seedance 按量调用，进 benchmark 可切换（已拍板混用+国产对照） | 护城河不在模型（Jasper 之死 + Higgsfield=聚合器实证） |
| ② 编排/step-runner 层 | **建（薄）** | ADR-0007 不动：AI SDK 起步+自研 step-runner 300-500 行；**抄 ad_video_gen 三件套范式**：session.state 黑板 / CallBackAgent 人话进度 / eval 抽卡 N→1（源码已留档，免费的老师答案） | 抄范式不抄栈（VeADK=Python，我们 TS；引 Python runtime 破坏架构 A 单体纪律） |
| ③ 体验层（Agent 工作台/brief 卡/候选/预审 UI） | **建** | KickArt 骨架当设计参考（02 报告）；这层=第一眼价值锚定=产品本体，外包/套壳即放弃产品 | 用户定调"UI/UX=核心竞争力之一" |
| ④ 垂类知识层（场景卡/Hook 脚本库/美业合规规则/门店档案/品牌音） | **建（唯一真护城河）** | 没有任何 vendor 出售美业到店垂类；WoZ 优选沉淀 | 已锁差异化=合规服务化+数据飞轮+陪跑 |
| ⑤ 成片工程层（视频合成/渲染/timeline） | **P0：模型端买 + 薄壳自建** | 视频成片=P0 主打（用户 2026-07-08 拍板）；Seedream 首帧+Seedance 片段（或即梦/可灵 API）直调 + 自建薄合成壳（ffmpeg 拼接+BGM+字幕+AIGC 标识烧录），ad_video_gen 的 moviepy+TOS 链整段范式平移到 TS worker，见 §3 | 源码已留档、合成段可整段抄；标识烧录必须自控（17 条义务） |

## 2. 路 2"订阅 KickArt 套壳"的两笔硬账 + 一个隐性风险

1. **License 数量级错配**：套壳需 API=旗舰版 ¥32.8 万/年（≈¥2.73 万/月）。按 Growth 599 满价，**46 家满配才刚 cover license 本身**（未计创点边际 ¥5-14/视频、模型、CAC、陪跑）。而我们验证期 Go 门槛=3 家 ≥399 付定金（≈¥1200 MRR）——差两个数量级。基础版 ¥16800/月无 API 不能套壳，且 WoZ 期 10-20 家收入（≈¥5000-1 万/月）也覆盖不了。
2. **护城河与合规义务冲突**：视频能力本身已匹配 P0，但套壳买到的是黑盒生成质量，不是我们的垂类知识、合规 gate、线索闭环和第一眼体验。同时 17 条自身合规义务要求自控关键链路（AIGC 显式/隐式标识注入率 100% 含导出文件、全链 correlation id 审计、DPA 处理者链透明）——黑盒产物拿不到这些控制点，KickArt 变 subprocessor 徒增合规面。
3. **隐性风险（轻记）**：字节系（KickArt/智能创作云商家版/即创）本就是竞品图第六分类"平台原生 AI"的贴身威胁；把它当底座=把美业垂类 playbook 喂给最可能下沉的竞对。

## 3. 视频成片的 P0 姿势（按用户修正重写）

**拍板**：P0 就做视频成片、且为主打功能之一；视频相关 P1 项并入 P0——视频脚本/分镜（原缓做）、轻视频成片（原 P1）、视频额度权益（原 P1）随之进 P0。

**技术路线（首选）**：模型端买 + 薄壳自建——
1. **生成**：Seedream 首帧 + Seedance 片段直调（或即梦/可灵 API，进 benchmark 可切换）；
2. **合成**：自建薄 worker（ffmpeg 拼接 + BGM/字幕 + **AIGC 显式标识烧录 + 隐式 metadata**），ad_video_gen 的 `moviepy+TOS` 链（release 段）整段范式平移到 TS；
3. **编排**：storyboard AIDA 四镜 → 批量首帧 → 评估抽卡 → 片段 → 合成，正好是自研 step-runner 的第一条重流水线（ADR-0007 的"流水线复杂度触发"点提前到来，是否届时引 Mastra 按原铁律走 Port 评估）。

**KickArt 旗舰 API 仍不订阅**：license ¥32.8 万/年的数量级账不因视频进 P0 而改变（46 家满配才 cover）；合规控制点（标识烧录/审计链）也必须自控。它保留为技术路线第三候选（Seedance 直调 → 即梦/可灵 API → KickArt API），仅当规模 ≥50 家且自建链被证伪时重估。

**三个必须跟着上提的工程件**：
1. **异步视频 worker + durable 任务**（原"Durable spike 缓做"上提 P0）：15s 视频实测生成 18 分钟，"提交即走+任务中心+连接桥通知"从体验优化变**生存必需**——新骨架（Agent 工作台+异步任务浮标）恰好为此而生；
2. **对象存储 + 转码/水印链**：视频文件的存储、AIGC 标识烧录、扫码转手机的流量成本进架构；
3. **视频额度计价**：按条进"按产出量卖"话术（"够发 X 条短视频"），边际成本（参考系：KickArt 创点边际 ¥5-14/条，直调应更低）由 spike 实测后定额度档位。

**Week-1 spike +1（五题变六题）**：Seedance/即梦直调 + ffmpeg 合成链 POC，四个验收指标=单条成本 / 端到端时长 / 质量可用率 / 标识烧录可行。

**WoZ 期**：人肉工具（即梦/剪映）仍可做对照与救急，但产品链路 P0 自建不省略。

## 4. 路 1"抄老师答案"的精确清单

**抄**（全部已有一手证据）：意图态主入口+轻侧栏骨架、Project→卖点卡→故事线→故事板→作品的对象链（流里跑库里存）、双合规门（输入端确权勾选+投前预审）、抽卡 N→1 评估（合规维度替换）、CallBackAgent 人话进度、白话能力档位、AIDA 分镜骨架、任务中心异步沉淀、货架式模板详情页（案例先行）。

**不抄**：Python/VeADK 栈（范式平移进 TS step-runner）、电商基因（商品 URL/带货剧情/100 条裂变）、企业级定价与私有化交付、逐镜专业编辑（默认收起）、零确认点黑盒（我们补双轻确认）。

## 5. 对已锁决策的影响面

- **P0 Scope Lock 变更（本轮最大影响）**：视频成片从缓做/P1 并入 P0 主打——supersede 范围收缩拍板④中"视频脚本缓做"子项与产品定义"视频脚本为 Go 后/P1"表述；连带上提：Durable 异步任务（原缓做）、视频额度权益（原 P1）。**图文渲染管线不联动**（非视频项，维持缓做，除非另拍）。P0 工程量显著加码，与"12 模块 vs 4-10 周"的评审张力由用户知情拍板（饱和开发资源、拒绝残缺 MVP 的既有工作方式）。
- **架构 A / 框架 B / ADR-0007：骨架不动，负载加重**。单 Node 服务旁挂视频 worker 属架构 A 预留的"三拆分信号"监测对象；视频流水线成为 step-runner 第一条重流水线，Mastra 重估按原触发条件走 Port 评估。
- **验证期 CF + 混用模型：不动**。视频生成走火山方舟/即梦 API（国内），与 CF 壳共存；火山生态记为中国化落地期云候选之一（CreatOK 用火山 TOS 是同行先例）。
- **UI 三分叉（02 报告 §6）**：骨架切换/货架形态/候选策略——与本报告 D 系列同批拍板；候选策略按媒介分层（文案多候选便宜、成片单发+免费重试）。
