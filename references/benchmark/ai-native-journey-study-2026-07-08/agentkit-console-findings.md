## 1. 这个模板是什么
**电商营销视频生成**（tpl-yebi04ewhsntl8dni7oe，火山官方）。定位=电商营销视频生成助手，把一条 pipeline 串起来：**营销策划 → 分镜脚本 → 图片生成 → 质量评估(抽卡) → 视频生成 → 合成发布**，产出单品宣传/活动促销类商品短视频物料。底层用火山系图片生成模型+视频生成模型；"抽卡评估"= 多产物生成后按质量择优。这与美业内容副驾高度同构：一个非技术运营者，用一句话意图驱动一条"策划→素材→成片"的多阶段内容生产流水线。

## 2. 详情页信息架构 (IA)
详情页**不是交互界面，而是单页锚点滚动的"模板说明书/落地页"**，页内 tab（锚点）= 案例 / 模板简介 / 场景案例 / 技术架构与功能模块 / 操作步骤。
- 模板简介: 名称+一句话能力
- 场景案例: 「电商视频生成」+ 预览图 + 架构图
- 技术架构与功能模块: 三标签(智能体运行时 / 可观测 / 身份与权限)+架构图
- 操作步骤: 五步图文引导（部署→试用）
即"先讲清这个 agent 是什么、能干什么、怎么落地"，把选择成本前置，再引导一键部署——**货架式而非空白创建**。

## 3. 交互范式（最重要）
详情页的操作步骤把用户旅程写得很直白，可提炼两个 AI 原生要点：
1. **一键部署 + 预置默认配置**：模板"已为您做好默认配置，可直接采用或按需修改"。把 agent 编排/模型/工具的全部复杂度折叠进默认值，用户只需勾协议→创建。这是"隐藏编排、暴露意图"。
2. **对话驱动试用 + 执行链路可视化**：部署后进"智能体运行时→在线测试"，原文「可以让 agent 帮忙生成产品的营销视频，我们可以在执行过程中**看到整个 Agent 的执行链路**」。即用户用自然语言下指令，agent 分步执行(策划/生图/生视频/评估/合成)，每一步在执行链路里逐步显形——这就是"agent 正在替你干活"的过程感载体。"抽卡评估"环节天然暗含**候选产物择优**的人类介入点。
> 注: 执行链路 UI 未直接目击（不部署）；但 Runtime 空态明写观测=「Runtime、会话、Trace 三维度全链路」，Trace 即逐步记录工具调用/子 agent/模型调用——过程感的技术底座确凿存在，对开发者是调试面板。

另一条 AI 原生范式在**智能工坊**：输入框「输入你想要创建的 Skill，或上传参考文件辅助生成」，Skill/Agent 双模式，**自然语言/传文件→AI 异步生成 agent**(prompt-to-app)，生成物注册到 Skills 中心复用。不是拖拽画布，是"描述即生成"。

## 4. AgentKit 对象模型（左侧导航）
- 顶层: 概览 / 应用广场 / 智能工坊 / 智能体运行时
- 基础组件: 工具 / Skills 中心 / A2A 中心 / 会话管理 / 记忆库 / 知识库
- 网关: MCP 服务 / MCP 工具集 / 身份与权限
- 评估评测: 评测集 / 评估器 / 实验
- 可观测(apmplus): Runtime/会话/Trace 三维
应用形态三类并存: **场景模板一键部署**(应用广场) / **NL 生成 Skill·Agent**(智能工坊) / **容器托管自定义 agent**(Runtime，Python/VeADK/镜像/CLI)。能力层(工具·Skills·记忆·知识·A2A)与我们评审中"AI SDK 起步、Mastra 推迟"的原语选型是同一抽象层。

## 5. 内容生成类模板清单（应用广场共 19 个，节选相关）
- **电商营销视频生成**: 策划→分镜→生图→评估→生视频→合成发布
- **绘影故事视频精灵**: 儿童故事→卡通绘本插画+分镜视频(5-15岁)

共性范式=**多阶段 pipeline + 中间产物评估择优 + 合成发布**。

## 6. 对美业副驾"旅程与页面排布"的启发
1. **入口=货架而非空白**: 别让老板娘面对空白输入框"从零建 agent"，给"像我的场景"模板(如"新客拓客九宫格""到店体验探店文")一键起步，默认配置全预置，用户只改一句话意图。对应我们"付费墙前置"可放到"选模板→看它替我干一次"之后。
2. **把"编排"折叠进默认值**: AgentKit 用"预置默认配置+一键部署"对非技术用户隐藏全部编排；我们的"六种风格/自检五关/密度测试"等框架内部逻辑同理，用户界面只暴露意图与产物，不暴露 pipeline 配置。
3. **过程感必须做，但要"拟人化旁白"不是"Trace 面板"**: AgentKit 的执行链路对开发者是调试台；老板娘要的是"正在帮你想卖点… 正在配图… 出了 3 版你挑一版"的一句话进度旁白 + 候选择优卡（呼应记忆里"拟人化一句话提醒>SaaS 待办卡片"与"专业口语折中"）。"抽卡评估→候选择优"正是天然的人类介入节点，值得移植成"三选一/换一批"。
4. **与传统 SaaS 控制台的异同**: 相同处—AgentKit 左侧导航仍是重对象模型(17 项)、面向开发者/管理员，信息密度高；不同处—**主入口被"场景货架+一句话生成"占据**，把"配置态"让位给"意图态"。给我们的取舍: 对内(创作者后台/合规)可保留 SaaS 式对象管理，对外(老板娘首屏)必须是意图态——一句话+一个像我的场景+看它替我干活，这与用户"UI/UX=第一眼价值锚定"的要求一致。
