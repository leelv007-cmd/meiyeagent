# KickArt（火山引擎 Muse Agent）AI 原生创作范式拆解

- 拆解对象：https://console.volcengine.com/kickart/welcome（真实计费 console，全程只读）
- 内部代号：muse-agent-web；交付三形态：SaaS / API / ArkClaw；计费=积分（"创点"）
- 抓取：opencli browser（CDP 复用本机登录态），DOM extract/state/eval + 官方产品介绍文档（docs/6664/2119705）
- 时间：2026-07-08

## 一、产品定位
一句话锚定=大标题「欢迎使用 Kickart」+ slogan「让好内容快人一步」。官方定性：**一站式营销、电商素材生产平台，通过 Agent 自主规划素材生成**，做"商家、广告主、创作者在内容时代的增长伙伴"。**客群是电商/营销商家（抖店/快手/小红书卖家），创作形态几乎全押短视频营销成片**（图文/海报只作为素材中间态，不是终产物）。这与我们"美业老板娘图文+视频"部分重叠但更垂直、更偏电商带货。

## 二、页面排布全图（混合式：左栏 IA + 对话式主工作区）
不是纯对话、也不是传统卡片堆叠，而是**"轻侧栏导航 + 单一对话式主工作台"**：
- 左侧栏（产品全貌 IA，5 组）：首页｜创意中心(AI特效模板)｜内容运营(**投前预审**·发布作品)｜内容空间(我的空间·版权空间)｜设置
- 主工作区（welcome=首页）自上而下三段：
  1. **中央大意图输入框**（contenteditable，非表单）——这是整个产品的主入口，占据视觉中心
  2. **热门功能** 4 入口：爆款裂变／视频混剪／自由创作／AI特效模板
  3. **灵感视频墙**：~30 条示例成片带时长角标，"做同款"复用
- 右下悬浮：任务中心（合成中心/上传任务，异步产物沉淀）+ 工具箱
- 顶部：积分余额 + 购买 + 任务中心 + 产品说明
导航"页"数很少：核心就是**一个工作台首页 + 若干功能子页**，重心全压在中央输入框，导航退居为轻辅助。

## 三、创作主流程（意图 → Agent 规划 → 成片 → 迭代）
**入口=意图输入框（对话式），而非模板墙或表单**。框内内嵌三种喂料方式并存：①直接打字描述；②「商品 URL/ID」粘贴抖店/快手/小红书链接，系统自动抓标题/图片/卖点；③「媒体素材」上传本地图/视频。下方 5 个意图 chips（品牌广告/好物推荐/测评对比/日常vlog/生活服务）一点即预填方向。
提交后进入**对话交互界面**，创作 Agent 自主规划、分步推进（文档描述的 5 步旅程）：
URL/素材抓取 → **素材理解**（AI"看懂商品"，自动提炼结构化卖点、识别主体、评估图片质量并给建议）→ **故事线生成**（一次性给 **4 条差异化创意**，各含标题/风格/时长，可"换一换"刷新或手改）→ **分镜故事板**（逐镜脚本+人物/场景/商品参考图，可替换/复刻）→ **一键成片**。
产物在"任务中心/合成中心"异步沉淀、在"我的空间"归档。**迭代路径丰富**：换一换（重生成创意）、局部重新生成（自由创作里改单个分镜）、做同款（灵感广场一键复刻爆款）、爆款裂变（1 爆款→最多 100 条批量裂变）。

## 四、AI 原生痕迹清单（逐条+出处）
1. **意图输入代替表单**：中央 contenteditable 输入框，说人话即可，无字段填写（welcome 首页）
2. **多形态喂料融进输入框**：URL/ID 抓取 + 素材上传 + 文字，三者同框（首页输入框内嵌按钮）
3. **模式=能力档位而非参数**：轻量/专业/进阶/快速 4 档，全用"极致性价比/全能高品质/高效出片/低至0.2创点"白话表达，把 Seedance 模型代际翻译成体感语言（combobox 实测）
4. **Agent 过程可视化**：进入对话界面后 Agent 自主规划、分步推进（抓取→理解→创意→分镜→成片），过程即对话内容（文档）
5. **生成式多方案+可刷新**：一次产出 4 条差异化创意，"换一换"重roll（AI 主动给选项，用户挑，而非用户配）（文档）
6. **产物即可迭代对象**：分镜故事板逐镜可替换/复刻，成片后局部重新生成（文档，自由创作）
7. **"做同款/爆款裂变"= 以产物为模板反向创作**：灵感墙/灵感广场任一成片一键复刻，批量覆盖 SKU（首页灵感墙 + 文档）
8. **自动化多步任务**：Agent 自主调度 LLM/生图/生视频/语音/音乐多模型串成一条视频（文档产品优势）
9. **发布前 AI 预审**：投前预审从"合规+是否优质"角度做抖音发布前审查（左栏，与我们合规角度强相关）
10. **异步任务中心**：生成不阻塞，任务后台跑、合成中心回收（右下悬浮 + 顶部任务中心）

## 五、对美业副驾客群（零基础老板娘）的适配判断
**可直接吸收（适合零基础）**：
- ①对话式意图输入取代分页表单——正是我们被批"卡片痕迹/传统 SaaS 痕迹"的解药，首页就该是一个"说出你想发什么"的输入框，导航退为轻侧栏。
- ②模式档位用"性价比/品质"白话而非模型名——老板娘只懂"便宜快 vs 好看贵"。
- ③AI 一次给 3-4 个方案 + 换一换——降决策成本，符合"不让用户从零配"的原则。
- ④灵感墙"做同款"——比空白输入框更友好的冷启动，美业可换成"同行爆款/项目案例"墙。
- ⑤投前预审——与我方合规护城河天然契合，可做成"发之前先帮你看有没有踩医美/功效违禁词"。
- ⑥异步任务中心 = 一句话拟人提醒的载体（与我们"拟人提醒>SaaS待办卡片"决策一致）。

**需警惕/给专业创作者的（老板娘用不上或过重）**：
- 分镜故事板逐镜编辑、@参考、局部重生成、跨行业跨语种复刻——属专业剪辑心智，老板娘会被吓退，应默认藏起、只在"高级"里露。
- 一次 10 商品×10 视频→100 条批量裂变——是电商投手的规模化诉求，美业单店 SKU 少，不需要批量军火库。
- 强电商基因（商品 URL/卖点/带货剧情）——美业核心是"到店服务+人设种草"，商品 URL 抓取要换成"项目/服务卡 + 门店场景 + 老板娘出镜"的喂料范式。

**一句话结论**：KickArt 的"**轻侧栏 + 中央意图输入 + Agent 自主分步 + 多方案换一换 + 产物即模板做同款**"这套骨架，正是我们要的 AI 原生页面排布；但它的电商批量军火味要剥掉，换成美业的"服务/人设/合规"内核，专业剪辑能力务必默认收起。

## 六、官方文档补充（docs.volcengine.com/6664，Jina 抓取 2026-07-08）
> 详见 sources/kickart-doc-billing.md 与 sources/kickart-doc-workflow-objects.md

### 6.1 官方定义与完整功能清单
- 官方定义：**一站式营销、电商素材生产平台，通过 Agent 自主规划素材生成**，服务营销/电商素材生产与 UGC 互动场景，做"商家、广告主、创作者的增长伙伴"。
- 创作形态：以短视频营销成片为唯一终产物（图文/海报/图片只作素材中间态）。
- 完整功能 9 项（各一句话）：①对话式一键成片(URL/素材→对话→成片)；②爆款裂变(爆款拆解+批量复刻，≤100条)；③自由创作(轨道级手动精修+AI生素材)；④视频混剪(多素材拼接+去重)；⑤投前预审(抖音发布前合规+优质度审查)；⑥发布作品(账号矩阵/跨平台/抖音扫码/抖音商家)；⑦AI特效模板(模板广场+API)；⑧版权空间(版权IP，如周星驰电影特效)；⑨商品库(SKU复用)。

### 6.2 产品对象模型（用什么名词组织产品）
以**「项目 Project」为顶层容器、由「对话」发起**，内部对象链：商品/商品库 → 卖点卡片 → **Storyline 故事线**(创意) → **Storyboard 故事板**(分镜) → **作品**(成片，沉淀于"我的空间-我的资产")。横向对象：素材/资产库(带AI标)、模板、版权IP、账号矩阵、任务、创点(计费)。**对象中英并置(Storyline/Storyboard)，是一等设计公民**——这正是我们规划中"对象化 vs 卡片化"的正解范式。

### 6.3 官方创作工作流与人工介入点
建项目→喂料+**确权**(读条款+勾"确权按钮"内嵌在提交动作)→卖点卡片(可编辑)→创意(编辑/换一个)→故事板(改图/对话重出)→分叉"一键成片"或"自由创作"→合成→发布。**每步都能"编辑修改/换一个"，也能一路默认直达成片**：重度可控 + 轻度可懒并存，是零基础与专业者通吃的关键设计。

### 6.4 计费/额度模型（重大差异发现）
**企业级订阅制，计费单位=创点**：基础版¥16800/月(600创点)、高级版¥72000/年(3000)、旗舰版¥328000/年(14000)；增项包约¥25-28/创点；API 仅旗舰版。单视频边际成本约¥5-14，但**起步门槛¥16800/月，是面向电商商家/广告主/MCN/代运营的 B2B 规模化定价**。

### 6.5 文档口径 vs console 实探差异
1. **定价错配**：welcome 页只露"积分余额0/购买/创点"，真实盘¥16800/月起只在文档可见——面向 B2B 规模客户，**与美业单店老板娘客群差一个数量级**，其页面范式可借鉴、商业模式不可照搬。
2. **合规是产品级机制**：console 只见左栏"投前预审"；文档揭示还有**输入端"确权按钮"+ 合规承诺函/虚拟人像合规承诺函**两份专门协议——形成"输入确权 → 发布预审"前后双合规门。对我方（强监管美业）是可直接抄的护栏范式。
3. **对象双语命名**在文档才显性(Storyline/Storyboard)，console welcome 只有意图框、进创作后才见。
4. **血统**：同文档中心挂着旧产品「智能创作云」(企业版/商家版/云编辑器/模板广场)，**KickArt = 智能创作云的 Agent 化新一代**——即"传统多页 SaaS → AI 原生对话工作台"的同厂演进样本，恰是我们要走的路径参照。
