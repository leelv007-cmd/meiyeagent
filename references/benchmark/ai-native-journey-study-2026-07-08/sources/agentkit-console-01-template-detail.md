## 操作步骤（部署→试用的用户旅程）
1. 点击"一键部署"按钮 → 跳转进入 Agent 应用部署界面
2. 部署界面已做**默认配置**，可直接采用默认或按需修改
3. 勾选产品协议 → 点击"创建" → 平台创建 Agent 应用（耗时若干）→ 完成后点"前往 Runtime 调试"
4. 进入"智能体运行时"界面，可看到一个已在运行的智能体
5. 点击侧边栏"智能体运行时" → 找到本次创建的 Agent 应用 → 点"在线测试"即可试用。
   > 「在试用时，可以让 agent 帮忙生成产品的营销视频，我们可以在执行过程中**看到整个 Agent 的执行链路**」

## 关键交互范式信号
- 部署是"模板预置默认配置 + 一键创建"，把编排复杂度对用户隐藏（低门槛）。
- 试用界面是**对话驱动**（"让 agent 帮忙生成…"）+ **执行链路可视化**（能看到 agent 每一步在干什么）——这是"agent 正在替你干活"的过程感核心载体。
- 中间产物（图片/视频/抽卡评估）在执行链路中逐步呈现；"抽卡评估"意味着多产物生成后择优，暗含"人可在候选中挑选"的介入点。
