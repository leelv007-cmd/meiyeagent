## 左侧导航 = AgentKit 对象模型（分组）
- **顶层**: 概览 / 应用广场 / 智能工坊 / 智能体运行时
- **基础组件**: 工具 / Skills 中心 / A2A 中心 / 会话管理 / 记忆库 / 知识库
- **网关**: MCP 服务 / MCP 工具集 / 身份与权限
- **评估评测**: 评测集 / 评估器 / 实验
- **可观测** (apmplus)

对象模型层次解读:
- 设计层: 智能工坊（造 Agent/Skill）
- 货架层: 应用广场（场景模板）
- 运行层: 智能体运行时（容器托管执行）
- 能力层(基础组件): 工具/Skills/记忆/知识/会话/A2A —— 与 AI SDK/Mastra 原语同层
- 网关层: MCP 服务/工具集 + 身份权限（对外暴露与鉴权）
- 质量层: 评测集/评估器/实验（离线评估）
- 观测层: Runtime/会话/Trace 三维在线观测

## 智能工坊 (Studio) — /agentspace
- 标语:「高效构建 AI Agent 与 Skill，加速能力从设计到运行，简化流程，快速落地」
- 交互核心 = **NL-to-Agent 生成器**:
  - 顶部切换 tab: `Skill` | `Agent`（两种产出物）
  - 输入框 placeholder:「输入你想要创建的 Skill，或上传参考文件辅助生成」
  - 即：自然语言描述 + 上传参考文件 → AI 自动生成 Skill/Agent
- "我的任务"区: 生成是**异步 task**，「任务会在创建后的 24 小时后自动删除，请及时将生成的 Skill 注册到 Skills 中心」→ 生成完注册到 Skills 中心复用
- 范式意义: 不是拖拽画布/表单配置，而是"描述即生成"(prompt-to-app)，把搭建门槛降到一句话。

## 智能体运行时 (Runtime) — /runtime（空态引导）
三步 onboarding:
- Step01 搭建智能体并构建镜像:「Runtime 支持运行主流 Python 框架开发的智能体，部署前需将智能体打包为容器镜像并上传，也可使用 AgentKit CLI 一键实现」
- Step02 在 Runtime 中部署智能体:「指定容器镜像 + 配置安全访问 → 托管至 Runtime，自动创建访问链接以支持调用」
- Step03 智能体全链路观测:「以 Runtime、会话和 Trace 三个维度监控全链路关键指标，实时洞悉性能/准确性/可靠性」
- 解读: Runtime = 容器化 agent PaaS（Python/VeADK/镜像/CLI），面向开发者；"在线测试/调试"发生在此层（对话 + 执行链路可视化，见 01 详情页）。

## 可观测 (Observability) — /apmplus
- 数据看板（无部署 agent 时空态，未取到数值），维度 = Runtime / 会话 / Trace。
- 这是"看 agent 干活"的技术底座：Trace 记录 agent 每一步(工具调用/子 agent/模型调用)。

## 对美业副驾的可迁移信号
- 两条搭建路径并存：**模板货架(应用广场) + 一句话生成(智能工坊)**，用户不必"从零建 agent"。
- "执行链路/Trace"是"过程感"的载体，但对开发者是调试面板；对老板娘需翻译成"拟人化进度旁白"。
- Runtime 面向开发者（容器/Python/CLI），这层复杂度对非技术用户**必须完全隐藏**——AgentKit 用"一键部署默认配置"隐藏它。
