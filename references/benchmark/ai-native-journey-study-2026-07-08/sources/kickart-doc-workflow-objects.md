# KickArt 官方文档补充 · 对象模型与创作工作流

- 源: 使用指南(2119708) + 一键成片新手指引(2512978)
- 抓取: 2026-07-08, Jina

## 产品对象模型（文档用这些名词组织产品，中英混用）
- **项目 (Project)**：顶层容器，一次创作=一个项目；由一次「对话」发起，沉淀在"我的空间-我的项目"
- **对话 / 新对话 (Conversation)**：主交互面；首页输入框提交 或 对话页"新对话"即新建项目
- **商品 / 商品库 (Product / Product Library)**：SKU 对象（图片/名称/受众/模特/卖点），可复用，"商品库选择"vs"新建商品"
- **卖点卡片 (selling-points card)**：Agent 解析商品后产出的可编辑卡片（用户标签/视频比例/时长/语言/卖点）
- **Storyline 故事线 / 视频创意 (Creative)**：一次生成 4 条差异化创意（标题/风格/时长），"换一个"重刷
- **Storyboard 故事板 (Storyboard)**：把人物/商品/场景/声音/分镜格式化呈现；仅 ≥15s 视频有格式化故事板
- **分镜 (Shots)**：故事板内逐镜，仅支持改图片、不支持改文字
- **素材 / 资产库 (Materials / Asset Library)**：上传或 AI 生成，AI 生成的左上角带"AI"标；分 全部/视频/图片/音频
- **成片 / 作品 (Work)**：最终产物，沉淀在"我的空间-我的资产-作品"
- **空间 / 我的空间 (Space)**：我的项目 + 我的资产(作品) + 版权空间
- **轨道 (Track)**：自由创作时间线
- **账号矩阵 (Account matrix)**：发布用的多平台账号集合
- **任务 (Task)**：批量生成单元（"生成X项任务"、批量裂变）
- **创点 (Credit)**：计费单位

## 创作工作流（对话式一键成片，含人工介入点）
1. **建项目**：首页输入框提交 / 对话页"新对话"提交
2. **喂料+确权**：输入商品URL(抖店/小红书；小红书快手首次需**店铺授权**) 或 商品ID 或 上传媒体素材(多图多视频) → 选模型档位 → 【阅读条款+勾选"确权按钮"】→ 点星标提交  ← **合规门内嵌在提交动作里**
3. **卖点解析**：Agent 提取卖点 → 出卖点卡片 → 【人工】选择性编辑(标签/比例/时长/语言/卖点) → "确认并进入下一步"
4. **视频创意**：Agent 生成 1 份最符合创意 → 【人工】"编辑修改"细调 或 "换一个"多次筛选 → "确认并进入故事板"
5. **故事板**：格式化呈现核心元素 → 【人工】"编辑修改"(仅改图片) 或 直接对话 Agent 让它重出整版
6. **分叉**：故事板可选"一键成片"或"自由创作"
   - 一键成片 → 自动合成 → 可再进自由创作精修 / 下载 / "发布视频"
   - 自由创作 → 手动导入或 AI 生成素材(生图片/生视频，@调取参考，选模型/参考类型/比例/时长/分辨率) → 轨道编辑/加BGM/局部切割/字幕 → "合成视频" → 作品
7. **发布**：作品右上"发布" → 账号矩阵 / 跨平台 / 抖音扫码 / 抖音商家
（生成期间 Agent 后台自行跑，用户可离开界面，回"我的空间-我的项目"找回）

## 爆款裂变工作流（批量）
首页 tab"爆款裂变" → 上传≤10 商品(商品库选择/新建) + ≤10 参考爆款视频(资产库/本地) → "生成X项任务"（产出数=商品数×参考数，最多100）→ 批量裂变界面(按状态筛选，可并行"新建任务")

## AI 原生要点（文档侧新增，未在 welcome 页显现）
- **确权按钮 + 阅读条款内嵌在"提交"动作**：把合规确认压进创作起点，而非事后审查（配合发布前"投前预审"形成前后双合规门）；另有 合规承诺函 / 虚拟人像合规承诺函 两份专门协议。
- **对象双语命名**：Storyline / Storyboard 中英并置，暗示对象模型是产品设计的一等公民。
- **"AI"素材标签**：区分用户上传 vs AI 生成的素材，可溯源。
- **人工介入点密集但可跳过**：卖点卡片/创意/故事板每步都能"编辑修改"或"换一个"，也能一路默认直达成片——重度可控 + 轻度可懒。
