## 产品概述（官方原话）
Kickart 是一站式营销、电商素材生产平台，通过 Agent 自主规划素材生成，服务营销、电商场景的素材生产场景和 UGC 互动场景，旨在成为商家、广告主、创作者在内容时代的增长伙伴。
平台依托自研创作 VLM 模型及领先的 Agent 架构，能结合营销场景、热点和输入信息，自主调度 Agent 能力，一键生成营销、电商素材。

## 核心功能（9 项）
1. **对话式一键成片**：输入商品URL/ID 或 上传素材图片/视频 → 进入对话交互界面 → 创作 Agent 结合输入/商品素材/卖点生成创意和故事板 → 生成完整视频。全流程轻交互、无门槛。
   - 流程 5 步：
     - URL素材抓取：粘贴商品链接/ID，自动获取标题/描述/图片。支持平台：抖店、快手、小红书。
     - 素材理解：AI"看懂商品"，自动提炼结构化卖点、识别商品主体、评估图片质量并给优化建议，支持手动补充。
     - 故事线生成：一次性生成 4 条差异化视频创意（每条含标题/风格/时长），自动匹配好物分享/剧情带货等类型，支持"换一换"刷新 + 手动编辑。
     - 分镜故事板：逐镜脚本 + 商品/人物/场景参考图，支持替换/复刻。
     - 一键成片，视频生成。
2. **爆款裂变（复刻）**：对上传的爆款视频做 多维拆解+结构化复用+原创重构 → 批量产出风格/结构/节奏相似但内容全新的合规内容。一次最多 10 商品 × 10 参考视频 → 生成最多 100 条。高光保留、分镜/画面级复刻、跨行业复刻、15-60秒超长复刻、多语种、本地化(模特/场景/文化)、支持虚拟人像。灵感广场"做同款"一键复刻覆盖海量 SKU。
3. **自由创作**：上传素材，@参考内容，自由组合图/文/音/视频多元素。一键成片后可快速编辑分镜、局部重新生成。适合成片精修/专业化创作。
4. **视频混剪**：上传多组已拍素材 → 系统拼接出自带音乐/转场的大批量视频，官方去重算法保质量。适合脚本固定的批量生产。
5. **投前预审**：从视频内容合规、是否优质角度，完成抖音发布前预审。注：结果仅供参考，不构成投放效果承诺。
6. **发布作品**：绑定多平台账号（账号矩阵），支持跨平台发布 / 抖音扫码发布 / 抖音商家发布。
7. **AI特效模板**：模板广场，支持预览 + API 调用。覆盖热门/节日/写真/搞怪多场景。
8. **版权空间**：展示获取的版权 IP，可参与创作。当前支持周星驰部分电影 AI 特效模板。
9. **商品库**：创建商品 SKU 信息（图片/名称/受众/模特/卖点），爆款裂变可复用，一次上传多次使用。（一键成片/自由创作暂不支持，计划中）

## 产品优势
- Seedance 2.0 模型：最高 60 秒视频（目前仅视频创作部分用 2.0，模板暂不支持）
- 链接输入一键成片：抖音店铺商品链接/ID 导入，自动提取卖点/受众
- 自研创作 VLM，叙事逻辑更符合营销视频风格
- Agent 自主规划：驱动故事板自主规划，调度 LLM/生图/生视频/语音/音乐等多模型
- 素材分发抖音等平台：创作→发布闭环
- 电商营销垂直
