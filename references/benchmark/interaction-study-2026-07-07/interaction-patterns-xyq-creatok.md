## 1. 小云雀网页版（xyq.jianying.com，剪映/字节系）

### 1.1 首页 = 对话入口 + 技能卡模板墙 + 精选作品

三层结构，从上到下：

1. **Agent 对话框为首屏中心**："Hi，和小云雀一起聊聊创作想法"。双 tab（创作 Agent / 短剧 Agent）。输入区 = contenteditable 富文本 + 全模态上传（image/video/wav/mp3/doc/docx/xls…）。
2. **输入框参数条（pills 形态）**：模型（默认"自动"）/ 创意助手开关 / 比例 / **自动时长** / @引用角色与素材 / 预设提示词（支持保存与导入 .json）。所有技术参数都有"自动"默认档。
3. **技能卡模板墙**（快捷模式 chips：画布模式/沉浸式短片/生成图片/产品推广/智能长视频 2.0 + 约 24 张场景卡）：爆款复刻、剧情广告、一镜到底、品牌大片、**节点营销**（节日大促/活动预热/直播引流/爆单促销）、**达人带货**（达人口播/场景种草/开箱测评/**前后对比**）、H5海报长图、万物一页纸、图片多尺寸延展、知识类视频、分镜脚本编写、品牌VI手册、一键批量去背景……每张卡 = 场景名 + 一句话说明。
4. **精选作品社区流**：他人作品可"**查看创作过程**"——把成品反向展开成教程。

### 1.2 技能卡点开 = 领域字段表单 modal（关键样本：节点营销）

左半 = 效果预览示例；右半 = 表单：

| 字段 | 形态 | 细节 |
|---|---|---|
| 商品图片* | 上传 0/10 | 必填校验前置（"请至少上传一个文件"） |
| 商品名称* | 文本 | placeholder = 真实示例值 **"显气色口红"** |
| 营销节点* | 选项组 | 超级大促(618/99/双11/双12) / 品牌活动(周年庆/换季清仓/开仓/品牌日/会员日) / 时令节日(开学季/年货节/情人节/春节) / **自动匹配** |
| 促销机制 | 文本 | 帮助文案"填写秒杀、限时限量、买赠、满减叠加等利益点提升转化下单率"；placeholder **"限时直降50元，买1送3"** |
| 视频比例 | 9:16 / 16:9 | 二选一 |
| 底部 | **编辑提示词** + 生成 | 表单编译为 prompt，专家可改；编辑提示词也要求必填项完整 |

**结论：面向非专业用户的"AI 能力"被封装成领域字段表单，prompt 工程完全隐藏，但保留"编辑提示词"逃生口。**

### 1.3 视频生成 = 一次性提交型 agent thread（实测样本：用户自己的"护发门店宣传片"）

- 创作历史打开后 URL：`tab_name=integrated-agent&thread_id=…&agent_name=pippit_video_part_agent`——**作品的组织单位是 agent 会话线程，不是"项目文件"**（Pippit = 剪映海外商业化产品线同源 agent）。
- 用户消息 = 一段约 200 字的完整 brief（上传环境参考图 + 全文语音文案 + "不要字幕、不要自加 logo、快闪节奏、电梯病毒式广告风格、16:9、15s"）。
- 时间戳：16:13 提交 → **16:31 产出（15 秒视频生成耗时约 18 分钟）**。
- 结果页无继续对话输入框（一次性提交型），操作全部是**整段级**：重新生成 / 提升画质 / 字幕擦除。没有时间线剪辑入口。

### 1.4 资产库：素材 / 角色 / 商品 / 画布 四类

- **角色**空状态："新增角色——**真人出演或上传 / AI 生成**"（人设资产三来源）。
- **商品**为一等资产类型。
- 生成产物自动回流素材库（"视频合成 - 分镜 - 泽发润复丝护发宣传片"自动入库）。
- 资产可在对话中 @引用。

### 1.5 短剧 Agent 2.0：剧本驱动 + 预置示例项目

- 三入口：上传剧本（txt/docx/pdf ≤10万字，版权确认提示）/ AI 生剧本（限免1次）/ 跳过直接进画布。
- **"我的项目"里预置官方示例项目**（"斗战三圣" 60 集、"旧教室的第三排" 3 集，标"示例"）——新用户零空状态，打开示例即学会结构。

### 1.6 其他

顶部常驻：下载客户端 / **CLI/API** / **连接 Agent**（对外开放 agent 生态接口）/ 积分余额 / 会员。

## 2. CreatOK（creatok.ai，TikTok 电商内容工作台）

### 2.1 Dashboard：单输入框 + 工具矩阵 + "做同款"探索流

- 口号："分析、复刻或生成爆款带货视频"。中央 tab：视频生成 / 图片生成 / 视频分析。
- 大输入框："描述视频画面内容和动态过程，使用 **@ 指定参考图或参考视频**"；参数 pills：模型（Seedance 2）/ 720P·9:16·8s / 参考·首尾帧·编辑 / 条数；生成按钮旁**明码标价积分**。
- 输入框三辅助按钮：**预设**（存 prompt 模板）/ **优化**（AI 改写 prompt）/ **向导**。
- **向导两档**：经典 = "选择场景方案，快速生成提示词"；高级 = "丰富模板 + **需求问答**，生成更精细的提示词"。
- 工具矩阵（电商工具箱）：爆款复刻 / 提示词反推 / 去字幕 / 商品套图 / A+内容 / 换装试穿 / 去水印 / 画质提升 / TTS / 多角度 / 图片翻译 / 视频翻译。
- 探索流：示例作品卡带 "**做同款**" 按钮（一键继承参数进创作）。

### 2.2 Agent (Beta)：技能 = 预填对话模板 + 槽位

- 定位口号："带货内容，一句话就有——**你的内容电商 AI 运营团队**"。
- 技能列表：一键创作带货视频 / 复刻爆款视频 / 拆解爆款视频 / 反推视频提示词 / 创作视频（从零开始）/ 创作图片。
- 点击技能后行为：**向对话输入框预填模板句**（"请帮我一键生成一条带货视频。商品 __"）并弹出结构化槽位（商品链接 / 视频链接 / 商品）——与小云雀"表单 modal"不同的第二种技能形态：**对话内联槽位**。
- 多模型选择器：Veo 3.1 Fast / Gemini Omni Flash / Seedance 2 系 / Sora 2 等。

### 2.3 视频生成器专页：场景词库 chips

顶部工具 tab（视频生成/爆款复刻/链接生视频/…/角色替换/动作控制）+ 右栏（历史/示例/精选）+ **场景风格 chips 词库**：产品展示、生活方式、穿搭分享、UGC种草、**前后对比**、**护肤日常**、**美妆特写**、好物日常、POV收包裹、故事带货、晨间日常……点击注入对应场景模板。

### 2.4 资产库：AI 生成 / 上传资产 / 数字人 / 商品库 / 回收站

- 与小云雀四类同构（数字人≈角色）；多配额可视化（0B/1GB）与回收站。
- 空状态一句话："还没有 AI 生成的内容——开始创作，你的作品将显示在这里"。
- 任务模型（上轮架构报告已证）：提交 + 轮询 + 失败退积分；历史列表为一等公民。

## 3. 交叉验证出的交互共性（两家独立收敛 = 行业已验证模式）

| # | 模式 | 小云雀 | CreatOK |
|---|---|---|---|
| A | 对话框是门面，**技能卡/场景模板才是小白主路径** | 24 张场景卡 | 技能列表 + 场景 chips |
| B | **prompt 工程被封装成领域字段**，保留专家逃生口 | 表单 modal + "编辑提示词" | 槽位预填 + "预设/优化/向导" |
| C | **示例即引导**：placeholder 用真实示例值；预置示例项目；作品可反向学习 | "显气色口红"；短剧示例项目；"查看创作过程" | 场景示例；"做同款" |
| D | **技术参数全部可"自动"**（模型/时长/节点匹配） | 模型自动/自动时长/自动匹配 | 默认 Seedance 2 + 预设档 |
| E | **资产四类**：素材/角色(数字人)/商品(+画布)；生成产物自动回流；@引用进创作 | ✔ | ✔ |
| F | **任务异步化**：提交即走，历史列表一等公民；结果只做**整段级操作**（重新生成/提画质/去字幕），无时间线剪辑 | thread 18 分钟 | 提交+轮询+退积分 |
| G | **每次生成明码标价**（积分在按钮旁） | ✔ | ✔ |
| H | 竖屏 9:16 为默认输出预设（匹配发布平台） | 可选 | 默认 |

**两家共同的空白（= 我们的位置）**：都假设用户自带 brief 能力（知道要做什么内容），都没有"该发什么"的经营建议、没有门店/账号档案记忆、没有周计划、没有发布后的线索/转化闭环。它们是"创作工具"，不是"经营副驾"。用户在小云雀实测写的 200 字专业 brief（语音文案+风格+禁止项+规格）恰是美业老板娘写不出来的东西——**那条 brief 就是我们产品要替用户自动生成的目标物的活样本**。

## 4. 对我们 P0 的参考映射（按 v1.5 范围过滤）

1. **"本周内容"入口做成美业场景技能卡**（已换容器）：本条的卡墙/表单形态已被 D3 改为 Agent 工作台中的场景 chips + brief 确认卡；AI 预填、Hook 独立成槽、价格字段隔离等内核保留。
2. **空状态 = 预置示例门店**（已换容器）：新工作区自带"示例美甲店"的结论保留，但呈现改为时间线里的 agent 演示流（只读、不计量、可隐藏）。
3. **素材库借鉴四类资产中的两类映射**：我们的"项目"≈商品、“人设”≈角色（v1.5 已有账号人设字段，不必新增角色资产模块）；**生成产物自动回流内容库/素材库**两家都做了，我们 P0 已规划（内容库），保持。
4. **结果卡只做整段级操作**：重新生成 / 换风格 / 换平台变体 / 存入内容库——两家生产级产品都没给小白时间线编辑器，佐证 v1.5 不做编辑器、图文渲染用模板的取舍正确。
5. **每次生成旁标注额度消耗**（模式 G）：透明计费直接影响付费心智，P0 只要求按钮旁消耗 + 余量常驻；完整 Usage Ledger 缓到 Go 后 / P1。
6. **异步任务交互**（模式 F）：生成中允许离开、完成回填历史——真视频生成 18 分钟/条的实测数据说明：**视频成片进入 P0 后，等待交互必须是"提交即走 + 连接桥通知"**，且成本要按分钟级生成时长进单位经济测算。图文渲染仍进入 Go 后 / P1 再按异步任务处理。

**不抄的**：自由画布（专业向）、爆款复刻（v1.5 已明确不押）、多模型选择器暴露给用户（违反我们话术原则，模型路由后台化）、CLI/API 与连接 Agent（生态动作，远超 P0）。

## 5. Agent 角色评估：指引 / 替代 / 加速

结论：**在这两家产品里，Agent 是"执行者"；在我们产品里，Agent 的增量价值在"指引"——这是两家都没占的位**。

- **指引（我们的核心差异，P0 主叙事）**：两家都从"用户已知道要做什么"开始；美业老板娘缺的恰是"这周该发什么"。我们的 Agent 用门店档案+素材库+营销日历替用户产出周计划和每条内容的完整 brief（= 用户在小云雀手写的那 200 字），把"想创意"这个最高门槛环节整体拿掉。首页拟人化一句话提醒（已拍板）是指引的最轻载体。
- **替代（P0 落地形态）**：替代 prompt 工程（场景卡表单→brief 编译）、替代选题策划（周计划）、替代合规初审（红线硬停+建议替换）。**不替代**发布动作（L3 交接）与拍摄（拍摄清单只指引）。
- **加速（P0 顺手）**：改稿快捷 chips（更口语/更专业/弱化广告感/加同城——v1.5 已有，与小云雀快捷指令同构，保持）、平台变体一键转换、素材上传自动打标。
- 边界佐证：两家的"向导/需求问答"（CreatOK 高级向导）都只是**辅助入口**，主路径仍是表单/技能卡——印证 v1.5 "副驾对话是第二入口、'本周内容'结构化入口是第一入口" 的排序，也印证 ADR-0007（这类交互用 AI SDK 的结构化生成即可支撑，无需重型 agent 框架）。
