## 证据索引

### XYQ-20260717-HOME-01：首页中心 Composer

- 路由：`/home?tab_name=home`
- 1440×1000 视口下，左侧主导航约 260px；中心 Composer 约 780×136px。
- 同一 Composer 内包含创作 Agent/短剧 Agent、全模态上传、自动模型、创意助手、比例、自动时长、@引用、画布模式、参考与生成。
- 首页下方继续承载快捷场景、技能卡和精选作品，不需要先进入独立工作台。

### XYQ-20260717-MODE-02：产品推广是 Composer 场景模式

- 点击“产品推广”后路由不变，Composer 内出现“产品推广”上下文标签。
- 推荐词切换为充电宝抖音带货视频、小云雀品宣视频、宫廷剧带货冷萃咖啡。
- 工具集合聚焦剧情广告、达人带货、品牌大片、节点营销、品牌 VI、H5 海报、品牌 Logo。
- 结论：场景模式是同一创作壳中的上下文切换，而不是独立产品导航。

### XYQ-20260717-FORM-03：达人带货结构化启动 modal

- 必填/可选字段：商品图片（0/10）、商品名称、卖点、视频比例、口播风格。
- 比例：9:16 竖屏、16:9 横屏。
- 口播风格：朋友安利、真实测评、开箱体验、试穿、自动。
- 底部保留“编辑提示词”与“生成”；缺少必填商品图时生成禁用。

### XYQ-20260717-ENTRY-04：首页提供两种画布入口

- Composer 参数条中有“画布模式”switch；切换后仅观察到 checked 状态变化，未提交生成。
- 技能入口中另有“自由画布（无限画布，无限创意）”，点击后进入 `/project`。
- 不把“自由画布”理解为免费；这里表示 free-form canvas。

### XYQ-20260717-PROJECT-05：project + 无限画布 + 自动保存状态

- 进入 project 后显示“未命名画布”和“已保存”。
- 顶部包含标题、保存状态、全局比例、积分/会员、分享、更新、用户入口。
- 全局比例菜单：9:16、16:9、21:9、3:4、4:3、1:1。
- 未做刷新恢复验证，因此证据只支持“观察到自动保存 UI 状态”，不支持 durable persistence 结论。

### XYQ-20260717-CANVAS-06：四种基础节点与画布工具

- 空画布可快速新建视频、图片、文本、音频。
- “添加节点”菜单也是四种基础节点；文本说明为“设定、台词、剧情说明”。
- 左侧 rail：添加节点、项目资产、帮助。
- 视口工具：重置、隐藏边、小地图、网格吸附、缩小、放大。
- 未创建节点，不宣称节点级 Agent 上下文、边类型、版本历史或时间线剪辑能力。

### XYQ-20260717-AGENT-07：画布与 Agent 同屏

- 1440px 视口下，默认画布约 940px，右侧 Agent 面板约 500px。
- Agent 面板可调宽、停靠左侧或右侧、收起；收起后画布扩展到完整 1440px，并留下“打开对话面板”入口。
- 面板提供多会话标签、新建会话、对话历史、会话分享、上传素材、自动比例、自动模型、创意助手。
- 未打开对话历史，未输入或发送任何消息。

### XYQ-20260717-ASSET-08：项目资产是画布内 modal

- “项目资产”打开对话文件 modal，不离开 project。
- 提供网格模式、目录模式、文件搜索；空状态为“当前对话中还没有文件”。

### XYQ-20260717-MODEL-09：模型路由在二级弹层

- 默认“自动”，视频/图片分 tab。
- 视频侧展示 Seedance 2.0 Mini/Fast/2.0 等分层；图片侧展示 Seedream 5.0 Pro/Lite、4.x 等分层。
- 未选择模型；该证据仅支持“主路径默认自动，模型细节按需展开”。
