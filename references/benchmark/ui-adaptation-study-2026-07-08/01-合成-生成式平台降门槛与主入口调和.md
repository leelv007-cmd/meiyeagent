# 合成：生成式内容平台降门槛研究 → 美业主入口调和方案

- 日期：2026-07-08 ｜ 四路调研合成（prefill 字段范式 + 即梦登录态实拆 + 可灵/Higgsfield 落地页文档级）
- 触发：用户"多关注生成式内容平台（即梦/Higgsfield/可灵），太工程化的参考不适合目标客群"
- 服务对象：v1.5 主入口设计（03 §3.2）+ 第 1 项 AI 预填决策的细化

> 2026-07-08 晚覆盖批注：本文 L0-L4 降门槛内核已被后续 D3 重容器化。最新主入口不是场景卡墙，而是 Agent 工作台：中央意图框 + 场景 chips + brief 确认卡 + 创作流。L0-L4、Hook 独立成槽、价格字段隔离和字段永不留空仍保留为内核。

---

## 0. 摘要

四路交叉验证出一个**最强共识**：面向零经验用户，降门槛的杠杆**不是"帮你把提示词写好"，而是"取消/绕过提示词"**——用视觉预设卡 + 传一张图/说一句话 + 一键出片替代打字。据此，v1.5 主入口应从"场景技能卡 + 领域字段表单"**软化为四层门槛梯度**（做同款占位 → 预设点选 → 对话追问 → 字段级编辑），但因我们是**经营内容**（价格/平台/合规是硬结构化事实），保留结构化骨架，不走即梦的"纯对话藏字段"。

## 1. 四路交叉的最强共识：取消提示词

| 路 | 证据 |
|---|---|
| 即梦（登录态） | 首页**没有**独立"AI帮写/扩写"按钮；降门槛靠"对话式 Agent+技能货架+自动默认+做同款"四件套 |
| 可灵（文档） | 创意特效整类**免提示词**：选特效→传1张正面照→生成；"参考图替代提示词"比"AI帮写"更彻底 |
| Higgsfield（文档） | 打包成品 Studio/App"Click once"；预设整类免提示词 |
| prefill（文档） | 门槛梯度：做同款/模板占位（最低）＜预设点选＜提示词扩写＜字段直填 |

**含义**：我们前一版口头建议里的"AI 帮写/prompt 扩写小功能"应降权——它只是门槛梯度的 L2，不是主战场。主战场在 L0（做同款占位）和 L1（预设点选）。

## 2. 完整门槛光谱（从低到高，各家实证）

| 层 | 形式 | 用户决策 | 第一方实证 |
|---|---|---|---|
| **L0 做同款/占位替换** | 模板 + "点此替换"槽 | 只换料 | 剪映可替换片段、可灵创意特效、Higgsfield App |
| **L1 预设点选** | 视觉预设卡墙 | 选卡+放内容 | Higgsfield Viral Presets、即梦技能货架 |
| **L2 说人话让 Agent 补** | 对话式共创/追问 | 说口语 | 即梦 Agent 模式、Dreamina Prompt Helper |
| **L3 字段级预填可编辑** | AI 预填真实值+可改 | 逐字段核对 | Shopify Magic、Amazon、Carbon 范式 |

传图/拍照贯穿各层，是**比打字低一个量级**的输入方式（可灵范式）。

## 3. 核心张力的裁决：结构化骨架 vs 纯对话

**张力**：即梦（登录态实拆）主张"别做字段表单，把字段藏进 Agent 追问，别摊 20 个空框"；字段范式（Carbon/Shopify）主张"做预填字段表单"。

**裁决 = 客群 × 内容类型决定**：
- 即梦=**开放创意**（想法发散），纯对话+追问合适；
- 我们=**经营内容**（引流/种草），价格不能错、平台要选对、医美红线要卡——这些是**不能漏、不能错的结构化事实**，纯对话会漏；且贴身竞品（小云雀/CreatOK）均走"技能卡+字段表单"。

**调和 = 结构化骨架 + 对话式血肉 + 视觉预设优先**：
- 场景卡定"这条内容必须有哪些要素"（骨架不能少）；
- 但字段**不摊成空表单**——用**占位槽预填门店真实数据**（L0）+ 缺失项**对话式追问**补（L2）+ 参数**视觉 chip 自动默认**；
- 深度定制才展开**字段级 AI 预填可编辑**（L3，带 revert+AI标注）。

即梦的"不摊空框"教训要听；但"纯对话零结构"对经营内容不适用。

## 4. 美业主入口内核（已被 D3 重容器化：L-1→L4 五层 + 三设计铁律）

整合四路（+ 即梦/可灵/Higgsfield 登录态实测）后的最终梯度。**L-1 贴链接零表单入口经 2026-07-08 实测降级为「待研究专项」，不进 P0 主入口（见 §4.1）**；P0 主入口 = L0→L4 四层实体，从最低门槛到最高控制，用户在任意层都能出活：

```
L0  场景 chips + 可展开货架（原场景卡墙收缩为伴随意图框的入口）
    每卡 = 成品预览缩略图 + 一句话"它替你做什么" + 使用量背书
         + 自带"该传什么图"引导文案（可灵范式，新手卡点前置）
    学 Higgsfield 打包成品 / 可灵特效库；弃可灵 128-工具网格
       ↓ 点开
L1  少数语义槽位（升级：不是大预设墙，是 2-3 个可点维度）
    美业 = 【内容类型】(探店/项目种草/客户案例/节日活动)
         × 【钩子/开场】× 【场景/风格】
    每维一个可视化 picker（看成品挑 > 读文字）+ 大白话描述
         + 客群语言分类（抖音/小红书/朋友圈）
    ★ Hook 独立成槽 = 预写"爆款开场脚本库"（老板娘最写不出、最该产品化的一层）
    选中预设即隐藏提示词框，直接"传图/拍照 → 出片"
       ↓ 做同款
L0.5 引导式向导（修正：不是静默填满，是预置 + 逐槽确认）
    点"做同款"→ 预置该模板槽位 → 逐个弹 picker 让用户确认/替换关键槽
    （纯静默填满会让老板娘"不敢动"；保留一次轻确认给掌控感）
       ↓ 想深改
L4  字段级 AI 预填可编辑（渐进式展开）
    字段永不留空、默认 = Auto/智能预填；专业参数默认收起（Advanced/Manual Off），想深控才点开
    带 inline AI 标可解释 + 编辑即接管 + revert-to-AI；价格字段不预填/隔离（Carbon 局部 presence）
```

**三条设计铁律（Higgsfield 第一方验证，写进设计规范）**：
1. **字段永不留空、默认=Auto/智能预填**——同一界面服务小白（全留 Auto 直接出）和专家（逐层钻进），靠默认而非空值逼选。
2. **渐进式展开**——专业参数默认收起，想深控才点开，保护小白、不挡专家。
3. **Hook/钩子独立成槽**——爆款开场做成可点选预写脚本库，美业引流内容最缺的一层。

输入方式：**传图/拍照优先，打字框次要**（可灵范式，呼应已拍板"上传入口做重"）。

**明确不照抄**：Higgsfield Apps 市场实为全栈 App builder（造 App，非填槽成品），与我们范式关联度弱（修正 kling-higgs 二轮理解）。

### 4.1 待研究专项：连接识别店铺/团单信息（价值成立·技术方案未定）

- **产品价值（成立）**：贴大众点评/美团/抖音团购链接 → 自动识别录入店铺档案/项目/价格，省手工录入，是最低门槛的建档入口（对标 Higgsfield Url to Ad）。价值不因当前做不了而否定，故立为专项而非删除。
- **当前难点（2026-07-08 实测）**：产品服务端（CF Workers 数据中心 IP）裸抓中国平台不可靠——点评首页裸抓即 302 风控；商家详情 JS 动态渲染（裸 HTML 是空壳）+ 价格字体加密 + 无第三方开放 API。**opencli 能抓是借本机 Chrome 登录态浏览器，≠ 产品服务端能力**（两者混淆是本条初版误判的根源）。
- **待研究技术方向（后续，不预设时点）**：
  1. **官方/商家授权能力**（最合规）：商家授权自己店铺的数据接口（美团/点评商家后台、抖音来客），走授权而非抓取。
  2. **商家侧登录态授权抓取**：用商家自己的登录态——但触及凭据托管，须与已移出 P0 的凭据保险库 / L2 群控 260 万判例红线一并评估（见 09 合规章 / ADR-0004），不可轻启。
  3. **第三方数据聚合服务**：采购，评估覆盖率/合规/成本。
  4. **无头浏览器渲染服务**：评估成本 + 持续反爬对抗的可持续性。
- **当前 P0 等价降级（已具备，不需新造）**：截图 OCR（冷启动价目表截图建档，03 §3.1）+ 粘贴文本，作链接方案成熟前的等价低门槛入口。
- **教训（防复发）**：本条初版由 Higgsfield 海外能力想当然平移、未做「外部现实轴检查」（中国平台反爬）而误列 P0——与本项目一直批评 Codex 的盲点同型。登记为专项以防再次当作已验证功能。

## 5. 贯穿要素

- **参数**：视觉 chip 点选 + 收益语（"人像更真/更省"，不暴露模型版本号）+ 自动/智能默认（强化已拍板"自动匹配"档）。
- **品牌音（新，建信任关键）**：学商家几条旧文案→生成带"门店口吻"；给"带品牌音 vs 不带"对照让商家确认"这是我的调性"，解掉"AI 味重、不像我"。接门店档案/账号人设字段。
- **做同款病毒回路**：作品 feed 一键继承。P0 可先做"本店已发内容做同款"；跨店同行 feed 需作品积累，评估 P1。
- **AI 标注**：字段级 Carbon AI label（点开可解释，不减分反增信）+ 内容级"内容由 AI 生成"（呼应 09 合规章 AIGC 标识，补 UI 形态）。
- **采纳即担责留痕**（Amazon 范式）：采纳节点确认，医美红线场景强制。
- **定价话术**：**按产出量卖**（"够你发一个月朋友圈 / X 条短视频 / X 张海报"），**绝不用积分/credit/模型数话术**（可灵产能换算是样板）；免费档可做可预览、付费墙卡"商用/去水印/下载高清"（可灵已验证有效，正是引流客群价值兑现点）。

## 5.5 登录态实测坐实（2026-07-08 二轮，可灵+Higgsfield 直证）

kling-higgs 二轮登录态实测把"取消提示词"从即梦旁证升为**两家直证**，并新增两个可直接抄的机制：

- **选中命名预设 → 提示词框消失**（两家一致实测）：可灵特效库 `/app/special-effects/new` 无 textarea、只提示"请上传一张图片"；Higgsfield 点 `FREE FALL` 提示词框整个消失、Generate 成本 96→54。→ **强化 L1：美业场景卡选中后直接进"传图/拍照→出片"，不给老板娘看提示词框；只有进阶"手动档"才露编辑入口（渐进式）**。
- **预设卡自带"该传什么图"引导文案**（可灵范式，新增高价值）：每卡内嵌"请传1张单人正面照、面部无遮挡、轮廓清晰"。→ 每张美业场景卡内嵌"请传1张正面店照/客照…"，把新手最大卡点（"我该传什么"）前置到卡片上。
- **参数 Auto 默认+可覆盖**（Higgsfield Cinema Style/Camera:Auto）+ **Generate 按钮内嵌积分成本**（"Generate 54"）→ 强化贯穿要素的"视觉参数自动默认"和"用量透明"。
- **Higgsfield 定位=多模型聚合器+编排层**（模型是可换后端、护城河在预设/运镜/导演编排层）——印证我方护城河不在模型、在场景卡/门店知识库编排。

**对四层方案的净强化**：② 做同款占位层补"选中即隐藏提示词框 + 卡片自带传图引导文案"；⑤ 贯穿补"Generate 内嵌成本"。主入口四层结构不变、更实。
