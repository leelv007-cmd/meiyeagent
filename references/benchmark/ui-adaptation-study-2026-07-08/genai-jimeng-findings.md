# 即梦（Dreamina）登录态深度实拆

- 调研：jimeng-deep agent（opencli browser CDP 复用本机登录态，全程 DOM 提取，未触发生成/导出，积分 80 未变）
- 编者注（合成时补）：本报告与 `prefill-editable-fields.md` 存在一个**核心设计张力**，合成时辩证处理——即梦主张"别做字段表单、用对话式 Agent + 追问把字段藏起来"，而字段级范式主张"场景卡+字段预填"。判断=客群差异（即梦=开放创意向；我们=经营向，需结构化门店数据+平台选择+合规卡点，纯对话会漏价格/平台/红线）。调和方向=**结构化骨架 + 对话式血肉**，非二选一（详见文末合成注）。

## 一句话结论

即梦降门槛主线**不是"帮你写提示词"，而是四层协同**：①对话式 Agent 范式（说想法，不写提示词）②打包的垂直"技能"货架（选 app 式选工作流）③全链路"自动/智能"默认档（不选参数也能出活）④作品广场"做同款"+提示词全公开（模仿式学习）。

## 逐项发现（带 DOM 原文证据）

**1. 主输入框/提示词门槛**
- placeholder 原文：**「输入想法、剧本或上传参考，支持"/"使用技能，添加主体，和Agent一起创作」**——教学式话术，非空的"请输入"。
- **首页没有独立的"AI帮写/扩写/提示词优化"按钮**。降门槛靠范式="和 Agent 一起创作"：大白话说想法 → Agent 扩写成大纲/分镜/参数。
- 两条非文字通道：参考图/视频上传（收 jpg/png/webp/mp4）+ 输入框内嵌"添加主体"→ 拍照代替打字，直击"不爱打字"。

**2. Agent 模式**：首页**默认模式**。形态=对话式共创（描述→Agent 产大纲/分镜/成片，技能描述写明"支持每个环节用户确认调整"=HITL 分步确认）。与"图片生成/视频生成"直接生成入口并列，后者是传统参数面。

**3. "/"技能面板**——4 个官方预设：剧情短片（自动生成故事大纲/分镜/短片）/ 电商套图（风格统一的商品全套视觉）/ 海报设计（营销场景+节日热点）/ 品牌设计（据公司名+业务+客群生成 Logo+视觉）。底部"用 Agent 创建技能 | 管理技能"。点技能→作为带图标 chip 插进输入框，结构化引导在提交后的 Agent 对话里（非提交前表单预填）。

**4. 技能市场**——按**业务垂直**组织：短剧影视(9)/电商营销(10)/创意艺术(8)/社交内容(7)/其他。每卡=标题+大白话用途（"当用户…时调用；不处理…"边界）+使用量+作者署名。技能=打包的专家方法论，可自然语言创建（可增长资产层）。

**5. 生成参数 UX = 视觉点选为主**
- 参数条极简，图片模式仅 3 chip：`[图片生成][图片 4.1][1:1·2K]`。
- **模型选择器=视觉卡片**（8 张带预览缩略图）+大白话卖点，不用懂版本号："图片4.6 人像一致性保持更好性价比更高 / 图片3.0 影视质感文字更准直出2k"。
- **比例=视觉比例框**，默认**「智能」**（系统判断）；分辨率 2K/4K。
- **「自动」默认档**：输出类型默认「自动」、比例默认「智能」。**参数全是"可改的默认值"，非必填**。

**6. 生成结果操作/做同款**（作品详情页实测）
- **「做同款」**=继承该作品 prompt+模型+比例到创作面，改几个字即出自己版本。
- **「用作参考图」**=直接当参考图喂新生成。
- **提示词全文公开可复制**=隐形提示词模板库，novice 抄爆款学习。

**7. AI 标注**：作品详情页明确标 **「内容由 AI 生成」**（DOM leaf 实测），符合国内 AIGC 标识合规。

## 对美业主入口的映射建议（jimeng-deep 原始）

1. 创作入口=单一对话框+教学式 placeholder，把美业字段藏进 Agent 追问，不一次性摊 20 个输入框。
2. "技能"=美业垂直货架，按**业务目的**分类（引流/种草/促销/复购），非技术能力（文生图/图生视频）。
3. 参数=可视化点选+收益语+自动默认，老板娘零选择也能出活。
4. "做同款"是 novice 最强杠杆，作品广场一键继承+提示词透明教学。
5. 合规内建：发布默认带「内容由 AI 生成」；医美走资质准入+红线硬停。
6. 降门槛≠帮写提示词：预算压在"对话式 Agent+技能货架+自动默认+做同款"四件套，而非 prompt 扩写小功能。

## 合成注（主 agent）：张力的调和

即梦"藏字段、纯对话"对**开放创意**成立；我们是**经营内容**，价格/平台/合规是不能漏、不能错的结构化事实。调和：
- **保留结构化骨架**（场景卡定"这条内容必须有哪些要素"），但**字段不摊成空表单**——用占位槽预填（门店真实数据）+ 缺失项用对话式追问补，参数用视觉卡+自动默认。
- 即梦四件套里**三件直接吸收**：垂直技能货架（=我们场景卡，按业务目的分类）、参数视觉点选+收益语+自动默认、做同款（作品广场一键继承）。
- **一件谨慎**：纯对话式 Agent 作主入口——我们仍维持 v1.5"结构化入口第一、对话第二"，但把结构化入口从"字段表单"软化为"占位槽预填+追问"，吸收即梦"不摊空框"的教训。
