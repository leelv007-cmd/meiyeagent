## 2. 主创作输入框（核心降门槛设计）
contenteditable textbox，placeholder 原文：
> **「输入想法、剧本或上传参考，支持 "/"使用技能， 添加主体，和Agent一起创作」**

DOM 证据：
```
[82]<div contenteditable=true role=textbox tabindex=0 />
  [81]<p /> <span contenteditable=false />
    输入想法、剧本或上传参考，支持 "/"使用技能， 添加主体，和Agent一起创作
    [80]<button>  // 输入框内嵌按钮（“添加主体”）
[77]<div id=...-reference-upload-0 />
  [76]<input type=file accept=image/jpeg,.jpg,.png,.webp,.bmp,video/mp4,... />  // 参考图/视频上传
```
关键判断：**首页没有独立的「AI帮写 / 扩写 / 提示词优化」按钮**。降门槛不靠"帮你写提示词"，而靠**范式本身 = 「和 Agent 一起创作」**：用户用大白话说想法，Agent 负责扩写成大纲/分镜/参数。辅以「上传参考」「添加主体」两条非文字输入通道（拍张图即可，不必打字）。

## 3. 参数条（输入框下方一行）——「自动」默认档是核心
```
[92]<div role=combobox>Agent 模式</div>      // 生成模式选择器
[94]<button><span>自动</span></button>        // 生成偏好（默认档）
[101]<div role=combobox>使用技能</div>        // "/"技能选择器

```

点「自动」→ 弹出 **「生成偏好」popover**（DOM 实测文案）：
```
生成偏好
  自动 | 图片 | 视频           ← 输出类型，默认【自动】
选择比例
  智能 | 21:9 | 16:9 | 3:2 | 4:3 | 1:1 | 3:4 | 2:3 | 9:16   ← 默认【智能】
其他设置
  图片 4.0 | 高清 2K            ← 模型版本 + 分辨率
```
**要点：输出类型默认「自动」、比例默认「智能」——用户完全不选，系统替他判断出图/出视频与画幅。** 参数全部是"可改的默认值"，不是必填项。

## 对美业映射的直接启示
- placeholder 是"教学式话术"（告诉用户可以做什么、怎么做），不是空的"请输入"——美业输入框应照抄这种"举例式引导 placeholder"。
- "自动/智能"默认档 = 老板娘不用懂比例/模型，直接能出活；参数是可选的可编辑默认值。
- 「上传参考 + 添加主体」= 用拍的照片代替打字，直击"不爱打字"痛点。
