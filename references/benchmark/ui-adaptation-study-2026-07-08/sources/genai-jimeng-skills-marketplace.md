## 关键设计模式
1. **技能 = 打包的专家方法论**：卡片描述里带「方法论/流程/工序」（如"九列分镜表""视觉基因解构""七步工序"），novice 不需要懂这些，选中即调用完整流程。
2. **"当用户…时调用；不处理…"式说明**：每个技能明确写清适用/不适用边界，帮零经验用户"选对工具"，避免用错。
3. **社区共创 + 使用量背书**：`来自·作者` + `146` 使用量 = 用社会证明降低"这个能不能用"的决策成本。
4. **底部入口**：「用 Agent 创建技能」「管理技能」——技能本身可由用户用自然语言创建（技能是可增长的资产层）。

## 对美业映射的直接启示
- 把美业场景做成**垂直技能货架**：如「到店引流短视频」「项目种草图文」「节日促销海报」「探店口播脚本」「前后对比图（合规版）」——每个技能=打包好的"美业老板娘工作流"，卡片用"当你要做…时用它"说明。
- 分类按**业务目的**（引流/种草/促销/复购）而非技术能力（文生图/图生视频）。
- 每个技能卡配一句"它替你做什么"的大白话 + 使用量背书。
