## A. 图片生成模式的参数条 —— 视觉点选为主
统一创作面，顶部模式选择器行：`Agent模式 / 图片生成 / 视频生成 / 音乐生成 / 配音生成 / 数字人 / 动作模仿`。切到「图片生成」后，参数条极简：
```
[图片生成]  [图片 4.1]  [1:1·2K]
```
仅 3 个 chip：生成按钮 + 模型 + 比例·分辨率。没有一堆表单字段。

### A1. 模型选择器（点「图片 4.1」）——视觉卡片 + 大白话卖点
DOM 实测 popup 含 8 张预览图（popupImgs:8），每张卡 = 模型名 + 缩略图 + 一句"它擅长什么"：
```
选择模型：图片 4.1 by Seedream 4.0 Design
  图片 5.0 Lite   指令响应更精准，生成效果更智能
  图片 4.7        画质全面优化，指令响应能力再次提升
  图片 4.6        人像一致性保持更好，性价比更高
  图片 4.5        强化一致性、风格与图文响应
  图片 4.1        更专业的创意、美学和一致性保持     ← 默认
  图片 4.0        支持多参考图、系列组图生成
  图片 3.1        丰富的美学多样性，画面更鲜明生动
  图片 3.0        影视质感，文字更准，直出2k高清图
```
**要点：用户不用懂"4.1 vs 4.6 差在哪"，读"人像一致性保持更好，性价比更高"这种收益语即可选。每个模型带预览缩略图 = 视觉化决策。**

### A2. 比例/分辨率选择器（点「1:1·2K」）
DOM 实测：
```
选择比例   智能 | 21:9 | 16:9 | 3:2 | 4:3 | 1:1 | 3:4 | 2:3 | 9:16    ← 【智能】=自动默认
选择分辨率 高清 2K | 超清 4K
尺寸       W × H (PX 自定义)
```
比例以视觉比例框呈现，且首选「智能」（系统判断）。

结论：**图片模式参数 = 模型视觉卡 + 比例视觉框 + 分辨率档位，几乎全是"点选缩略图/档位"，而非填数字表单。**

### B1. 做同款（参数继承）
- **「做同款」** = 把该作品的 prompt + 模型(图片4.1) + 比例(3:4) 继承到创作面，用户改几个字就能生成自己的版本。
- **「用作参考图」** = 直接把这张图当参考图喂给新生成（图生图路径）。
- 提示词**完整公开**：novice 可以直接抄大神的 prompt 学习/复用，等于"隐形的提示词模板库"。

### B2. AI 标注
- 详情页明确标注 **「内容由 AI 生成」**（leaf 文本节点，DOM 实测 `AI 生成: 内容由 AI 生成`）。
- 符合国内 AIGC 标识合规（生成内容显式标注）。

## 对美业映射的直接启示
- **参数一律做成"可视化点选 + 收益语"**：模型/风格/比例给缩略图和"它适合什么"，不给技术参数名。默认值走"智能/自动"。
- **「做同款」是 novice 最强杠杆**：美业作品广场每条案例都应支持"一键做同款"（继承文案结构+风格+参数），老板娘照着爆款改自家信息即可。
- **提示词/参数透明**是隐形教学：展示"这条爆款用了什么"，让用户在模仿中学会。
- **AI 标注「内容由 AI 生成」必须内建**（合规硬约束），美业发布链路要默认带 AIGC 标识。
