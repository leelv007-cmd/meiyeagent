**视频生成**：文生视频、图生视频、图片/主体参考、动作控制、数字人、智能分镜、指令变换、视频参考、创意特效、对口型、定制模型

**图片生成**：文生图、参考生图、风格转绘、局部重绘、扩图、消除笔、AI模特、AI换装

**音效生成**：文生音效、视频生音效

**app 侧边栏常驻入口**：Omni、图片生成、视频生成、动作控制、灵动画布、Agent、数字人 2.0、创意圈、资产、订阅计划、会员有礼

# 二、创意特效（/app/special-effects/new）——零提示词模板机制
流程：**① 选特效 → ② 上传一张单人图片（引导语：正面照、面部无遮挡、轮廓清晰效果最佳）→ ③ 点生成**。全程不写提示词。
分类 Tab：**全部 / 趣味动作 / 风格变身 / 运镜 / 剧情**。
模板举例（数十个，卡片缩略图点选）：一键变手办、一键3D拍立得、一键变果冻、美式证件照、老照片动起来、亲亲嘟嘴、飞吻、单人比心、魔力转圈圈、万物膨胀、捏捏乐、子弹时间、镜头推进/拉远、变身大明星、圣诞/万圣/春节等节日模板……

# 三、文生图创作页（/app/image/new）——提示词降门槛 & 参数形态
- 提示词框占位引导原文：**"可以直接描述想生成的图片内容，或使用 Deepseek 反推 描述图片，也可查看 使用指南 提升生成效果"**
  - **Deepseek 反推** = 上传图片让 AI 反推出提示词（图→词），零经验用户不用自己憋文案。
  - **使用指南** = 直接链到官方图文教程。
- **风格词库** 按钮 = 视觉风格预设库入口（点击弹层，未登录点「生成」会弹「开通个人版会员」）。
- 参数形态：**视觉化 chip 点选**，底部一行「2K高清 · 3:4 · 2」（画质 / 比例 / 出图张数），侧栏「参考生图（可选）0/10」（最多传 10 张参考图）。整体是「一句话 + 点几个预设 chip」，非长表单填空。

# 四、创意圈（/app?ac=1）——内容发现 + 做同款
- 顶部 Tab：推荐 / 关注 / 活动 / 发布作品。
- 发现页分类标签（正是风格模板体系）：短片、赛事现场🔥、4K、3.0模型、动作控制、首尾帧、**赛博科幻、壁纸海报、动漫动画、绘本插画**、教程。
- 作品瀑布流：缩略图 + 作者 + 点赞数；作者含大量「快手用户」「XX本地团购官」等本地商家/素人。
- **做同款机制（已验证）**：点击创意圈里的「创意特效」作品 → 跳转 `klingai.com/app/effects-template?rid=<作品id>`，直接进入**该特效模板待上传状态**（即"用同一个特效做我的"）。另有 `/app/hot-rank/<特效名>` 特效热榜。普通文生图/视频作品的「继承提示词+参数做同款」按钮需登录态进入作品详情才可见——当前未登录仅能确认特效类做同款路径。

### 六问对应结论速查
1. 功能全景 = 上述 128 工具，卡片式分「视频/图片/音效」三大组 + 模型推荐置顶。
2. 提示词降门槛 = Deepseek反推(图→词) + 使用指南直链 + 创意特效整类免提示词 + 参考图代替文字。
3. 模板/风格库 = 视觉卡片式（创意特效缩略图、风格词库、创意圈风格分类），点模板即预置。
4. 做同款 = 特效类经 effects-template 一键继承（已验证）；文/图做同款需登录。
5. 参数形态 = 视觉 chip 点选为主（画质/比例/张数/参考图槽位），几乎无传统表单。
6. 定价见 genai-kling-pricing.md。
