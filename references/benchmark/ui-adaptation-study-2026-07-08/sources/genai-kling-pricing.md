# 「灵感值」规则（官方 point-policy 摘录）
- 定义：可灵 AI 平台内虚拟道具，**绑定快手账号**才能获得/兑换；非货币、不可提现、不可反向兑换人民币。
- 标准定价：**1 元人民币 = 10 灵感值**（不定期有优惠活动）。
- 类别与有效期：
  - 运营活动灵感值 / 会员权益灵感值（订阅后按月发，有效期 1 个月）/ 7天会员权益（7天）/ **登录灵感值（会员每日登录/访问领取，当日 24:00 清零）** / 购买灵感值（充值后有效期 2 年）。
- 消耗：生成动作发生时即扣，生成失败退回；优先消耗剩余有效期短的。
- 会员到期后：充值/活动灵感值不受影响，订阅赠送灵感值有效期 1 个月。
- 余额查询：网页侧边栏「灵感值详情」；APP「我的-右上角灵感值-明细」。
- 非会员即便有灵感值，**快速生成通道、1080p、去水印、运镜、视频延长、画质增强等仍是会员专享**。

### 关键观察（面向非技术美业商家）
1. 免费档靠「每日登录送灵感值」养留存，但**免费生成不可商用** → 想拿去引流获客的商家被迫升级到黄金档（46 元/月起）。
2. 分档纯用「灵感值额度 + 产能换算（约 X 张图 / X 个视频）」讲卖点，非技术用户能直接看懂「这个月够我发多少条」。
3. 主体创建数量随档位递增（30→500），是隐性的「数字人/固定 IP 形象」用量限制。
