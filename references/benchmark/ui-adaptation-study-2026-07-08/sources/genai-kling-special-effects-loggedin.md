# 可灵 Kling — 创意特效（Special Effects）模板库 · 登录态深入

- 来源 URL: https://klingai.com/app/special-effects/new
- 抓取日期: 2026-07-08
- 抓取方式: 登录态深入（opencli browser DOM 提取，session=klingdeep）

## 页面结构（降门槛核心样本）

三栏式：**左=创作区（选择特效 + 上传槽 + 生成按钮）**，右=**特效库面板（分类 Tab + 视觉缩略图卡）**。

- 页面标题：`创意特效` / `Kling AI Special Effects`
- **无提示词输入框（无 textarea）**——纯模板驱动，用户零文字输入。
- 左侧创作区文案：
  - `选择特效`（当前选中的特效名，如"巴西·射门"）
  - 上传要求（随选中特效变化）：`请提供一张单人图片` / `正面照、面部无遮挡、轮廓清晰的照片效果最佳。`
  - 上传槽：`请上传一张图片` + `历史创作`（复用历史素材入口）
  - 底部合规提示：`内容由AI生成，禁止利用功能从事违法活动`
  - 唯一操作按钮：`生成`（未点击）

## ① 预设组织方式：视觉缩略图卡 + 7 大分类 Tab

分类 Tab（右侧面板顶部）：
`全部` / `趣味` / `动作` / `风格` / `变身` / `运镜` / `剧情`
（另有 `我收藏的` / `资产管理` 入口）

每张预设 = 视频缩略图（img，多为效果成片预览）+ 特效名 span。共 **89 个特效预设**（全部 Tab）。

## 关键机制：点一个预设 = 零输入预填全套（已实测验证）

实测点击"老照片动起来"卡片：左侧"选择特效"从默认"巴西·射门"**即时切换**为"老照片动起来"，URL 不变（SPA 状态切换），仅提示"请上传一张图片进行特效制作"。
**提示词 + 运镜 + 时长 + 参数全部烘焙进模板，用户不可见也无需填**；用户唯一动作 = 上传 1 张图 → 点生成。真正的"零输入出片"。

每个预设卡**自带上传要求 placeholder**（模板自描述需要什么图），少数需 2 张图或 2-12 张图。

## 对美业内容副驾的启示
- 特效库 = "视觉卡 + 分类 Tab + 零输入模板" 是可灵最强降门槛结构：把复杂 prompt/运镜工程完全隐藏，用户认知只剩"挑一个喜欢的效果 + 传一张图"。
- 模板自描述上传要求（每卡 placeholder），把"该传什么图"这个新手最大卡点前置说清。
- 美业可直接对标场景：美式证件照/形象照、老照片动起来、变身大明星、一键3D拍立得、亲亲嘟嘴/比心（人像微表情）。
