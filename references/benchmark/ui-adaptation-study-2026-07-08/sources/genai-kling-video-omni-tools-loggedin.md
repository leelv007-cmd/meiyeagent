## A. 视频创作 / 首尾帧（/app/image-to-video/frame-mode/new → 重定向 /app/video/new）
统一视频创作台，首尾帧是其中一种输入模式。
- 模型卡：`视频 3.0`，副标 `音画同步升级，主体一致性增强，支持多镜头叙事`
- 首尾帧上传槽：`添加 首尾帧图` + `历史创作`（非分离的首帧/尾帧两槽，而是统一"添加首尾帧图"）
- 提示词框（contenteditable），引导原文：
  > `用引号""标注角色说话/唱歌内容，例如：主持人说"看那远方的星星"，支持多种语种、方言、口音。点击 学习更多prompts写作技巧。`
  > 链接：`视频 3.0 功能使用手册`
- 分镜模式 chip：`智能分镜` / `自定义分镜`（叙事分镜切换）
- 参数折叠 chip：`1080p · 5s · 16:9 · 1`（画质·时长·比例·数量）+ `音画同步`（开关）——全视觉点选，无手填

## B. Omni 多模态（/app/omni/new）
多模态**指令编辑台**：自然语言指令驱动的改图/改视频。
- 顶部大类切换：`视频生成` / `图片生成`
- 子模式 chip：`图片/主体参考` / `图生视频` / `指令变换` / `视频参考`
- 提示词框接自然语言指令，示例（历史）：`将视频中女生的衣服换成白色瑜伽服，头发换成短发，门的颜色改成蓝色`——指令式编辑
- 参数：`1080p · 5s / 10s`
- 模型：`可灵 Omni`、`视频 O1`

## ⑤ 已生成作品的整段级操作（历史流卡片，实测 hover 浮层）
对已完成作品 hover 露出工具条（视频作品为例，实测原文）：
- `去 Omni 创作`——把该作品带入 Omni 二次创作（≈做同款/复用/参数继承入口）
- `对口型`——给视频加口型/配音
- `抽帧`——抽取视频帧
- 下载：`视频 MP4/MOV`、`无品牌水印`（付费去水印/多格式导出）
- `收藏`、`举报 / 删除`
- **图片作品的整段级增强**走 all-tools 对应工具：`局部重绘`(inpaint) / `扩图`(outpaint) / `AI换装` / `风格转绘`
- 注：视频"延长/续写"类操作需进入作品详情视图才展开，本次为规避误触生成按钮未深入触发。

## 对美业启示
- 视频降门槛：首尾帧统一槽 + 智能分镜 + 音画同步开关，把"分镜/配音/口型"这类专业环节收成一两个开关。
- Omni 指令式编辑（"把衣服换成白色瑜伽服/门改蓝色"）= 非技术用户最友好的改图范式，自然话即改。
- 作品级复利：`去 Omni 创作`(做同款) + `对口型` + `局部重绘/扩图/AI换装`，形成"生成→增强→复用"闭环，美业可对标"改妆造/改门店色/加口播"。
